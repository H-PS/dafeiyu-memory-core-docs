## §5 方法附录

1. **计数/失配**：`Get-ChildItem -Recurse -File` 全量枚举（实测 6116）；失配=目录名前 10 位日期 ≠ `LastWriteTime` 日期。
2. **哈希**：`Get-FileHash -Algorithm SHA256` 全量 6116 文件（唯一 4173、重复组 439、重复文件位 2382）；与父 Agent 哈希对账结论（5983 一致/133 独有/174 备份独有）互为印证。

4. **敏感内容**：仅匹配文件名/键名/密钥样式正则（`sk-`、长 token 串），确认存在即止，**不复制内容**。
5. **复现命令样例**：
