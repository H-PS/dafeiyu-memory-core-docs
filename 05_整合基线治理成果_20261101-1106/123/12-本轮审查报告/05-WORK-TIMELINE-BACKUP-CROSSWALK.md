## 6. 优先审查规则（建议写入索引）

```
优先级 = ① 是否有机器合同（schema/config/DDL）
        → ② mtime 是否最新（按单文件，不按目录）
        → ③ 是否有裁决依据（08-adjudication-ledger / DD-AUTHORITY）
        → ④ 是否被别的文档引用为"基线"
```

按此规则，本轮及后续应：

1. **先审** `work\Memory-Core-R4.1-Design`（唯一合同集，最新）。
2. **再审** `work\14/15`（实施规格；与 canonical 的差异必须逐条对齐）。
3. **时间流只作历史证据**：用于追溯决策来源、找回被删方案、核对版本演进；**不作为当前基线**。
4. **备份全集只作字节参照**：用于证明"是否被改过"，不作为阅读对象。
