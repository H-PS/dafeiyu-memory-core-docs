## 二、逐项对照

### 2.1 PAD（Mehrabian & Russell 1974）

**原文**：情绪可用三个正交维度描述——Pleasure / Arousal / Dominance。

**本方案**：`P/A/D` 三个连续变量，范围 [−1,1] / [0,1] / [−1,1]。

**改动**：无。

**为什么用它**：三个数就能分出 8 个情绪族，且天然可映射到表情/语音/动作。比离散标签好。

---

### 2.2 ALMA 三层（Gebhard 2005）

**原文**：

```
Personality（不衰减）→ Mood（小时级）→ Emotion（分钟级）
```

**本方案**：

```
base（不衰减）→ mood（τ=240min）→ emo（τ=25min）
```

**改动**：
- ALMA 用 PAD + Big Five 映射，本方案直接用 base 的 PAD
- **加了溢出机制**（ALMA 没有）：emo 到顶后，溢出量转入 mood

**为什么加溢出**：压力测试发现，不加的话 emo 到顶就"免疫"了，重复刺激完全无效。ALMA 是为短时对话设计的，不涉及长期累积。

---

### 2.3 Scherer SEC（2001）

**原文**：刺激评估有多个层级——新颖性、内在愉悦、目标相关性、期望一致性、因果归因、应对潜能、规范相容性。

**本方案**：

```
R 相关性 / C 一致性 / G 归因 / K 应对 / N 规范 / O 确定性
```

**改动**：把 Scherer 的 10+ 项压成 6 项，去掉"新颖性"（合并进 intensity）。

**为什么压**：每一项都要从文本抽，抽得越多错得越多。6 项是"能算准"的上限。

---

### 2.4 OCC（Ortony, Clore & Collins 1988）

**原文**：22 种情绪，由「事件/行为/对象」×「愉悦/赞否」×「他人/自己」组合而成。

**本方案**：**只抄了结构，没抄列表。**

用 8 象限（Mehrabian）+ 评估痕迹（gSelf/gOther/normViol）推出社会情绪：

| 条件 | 读出 |
|---|---|
| normViol + gSelf + coping 高 | 内疚 |
| normViol + gSelf + coping 低 | 羞耻 |
| normViol + gOther | 愤怒 |

**为什么不用 22 种**：离散标签不能当状态（会卡死），只能是读出结果。而且 22 种里大部分在对话里用不上。

---

### 2.5 Bower 联想网络（1981）

**原文**：情绪是记忆网络中的一个节点，激活后沿语义联系扩散，优先激活同情绪色调的记忆。

**本方案**：`emotionalCongruence()` + `spreadActivation()`。

**改动**：
- 同向加分（+0.7×|P|×|v|），反向减分（−0.45）
- **加了自我安抚槽位**（Bower 没有）

**为什么加自我安抚**：Bower 的理论只描述"同向优先"，但临床观察发现严重抑郁者仍能回忆正面事件（只是更难）。完全排除会让模型变成刻板印象。

---

### 2.6 peak-end 规则（Kahneman 1993）

**原文**：对一段经历的记忆，由**最强时刻**和**结束时刻**决定，与持续时间无关（duration neglect）。

**本方案**：

```
valence = 0.5×peak + 0.3×end + 0.2×avg
```

**改动**：加了 0.2 的 avg 项。

**为什么加**：纯 peak-end（0.5/0.5）会让"持续的小确幸"完全不留痕。加 20% 平均值留一点底。

**实测**：

| 序列 | 结果 |
|---|---:|
| [+0.2, +0.1, −0.8, +0.1, +0.2] | **−0.348**（avg 只有 −0.04） |
| [−0.7, −0.5, 0, +0.4, +0.6] | −0.178 |
| [−0.3, +0.8] | +0.69 |

---

### 2.7 Easterbrook 倒 U（1959）

**原文**：唤醒升高时，线索利用范围先扩大后收窄（cue utilization）。

**本方案**：

```
capacity = 2 + 3 × exp(−(A − 0.45)² / 0.12)
```

**改动**：峰值放在 0.45 而不是 0.5。

**为什么**：人最专注时不是最兴奋时，是略微平静的时候。

**实测**：

| A | 容量 |
|---:|---:|
| 0.00 | 2.55 |
| 0.45 | **5.00** |
| 1.00 | 2.24 |

---

### 2.8 Collins & Loftus 扩散激活（1975）

**原文**：语义记忆中，激活从概念节点沿连线扩散，距离越远衰减越大。

**本方案**：`spreadActivation()`，**只做一轮**。

**改动**：不做迭代到收敛。

**为什么**：两轮之后几乎所有记忆都被点亮，等于没有注意力。一轮 = "顺带想起一件事"，正好。

---

### 2.9 「心识」的顶点机制（deploy-kit）

**原文**：

```js
if (peak[k] >= 0.85 && now - peakAt[k] > 30min) {
  unmet[k] += 1;
  peak[k] = 0.55;
  traits[tk] += 0.01;
}
```

**本方案**：移植，但阈值从 0.85 改为 0.60。

**为什么改**：心识的离散情绪可以单次置到 1.0，本模型的 PAD 受 `dPMax` 护栏限制，单次只有 0.27。必须按量程重标定。

**实测边界**：

| 间隔 | 到顶点需要 |
|---|---|
| 3 分钟 | 2 次 |
| 10 分钟 | 2 次 |
| 20 分钟 | 8 次内到不了 |

## 三、本方案独有三处

### 3.1 L 扭曲评估

**所有对照的成熟系统，都假设评估是客观的，只有情绪被扭曲。**

本方案让**负荷 L 反过来扭曲评估**：

```js
R' = 1 − (1−R)(1 − 0.5·L)      // 阈值下降
C' = C·(1 + 0.6·L)  若 C<0     // 负性放大
K' = K·(1 − 0.45·L)            // 应对感削弱
```

**心理学依据**：appraisal bias / mood-congruent appraisal（Bower、Beck）。

**为什么重要**：这是「不是对方变了，是你的阈值变了」的可计算版本。同一句话在 L=0.1 和 L=0.9 下是完全不同的两个事件。

**实测**：

| L | 同一件小事的 ΔP |
|---:|---:|
| 0.1 | −0.025 |
| 0.9 | −0.073 |

**差 3 倍。**

### 3.2 溢出转心境

ALMA 的三层是**独立衰减**的，情绪层到顶后不会影响心境层。

本方案加了溢出：

```
emo 到顶 → 溢出量 × 0.15 → mood
```

**为什么重要**：这是"今天真是糟透了"的形成机制。没有它，情绪层到顶后模型就"免疫"了。

**实测**：8 次攻击才到 P=−1.0（没有溢出时是 2 次）。

### 3.3 自我安抚槽位

Bower 的联想网络只描述"同向优先"，没说反向会怎样。

本方案在极端情绪下**强制保留一条反向记忆**。

**为什么**：完全排除会让角色变成刻板印象。真实的人再难受也会想起一点好事。

**实测**：

| P | 选中 |
|---:|---|
| −1.0 | `−−−−+`（留一条好的） |
| +1.0 | `++++−`（留一条坏的） |

## 四、成熟方案里本方案没有的

| 能力 | 谁有 | 本方案 |
|---|---|---|
| 22 种 OCC 情绪完整映射 | ALMA | 8 象限 + 6 种社会情绪 |
| Coping 策略库 | EMA | 只有 K 一个标量 |
| 需求动力学（PSI） | Dörner | 三个 need 的简单回归 |
| 规划/意图推理 | FAtiMA | 无 |
| 社会规范建模 | EMA | 只有 N 一个标量 |
| 多角色关系图 | FAtiMA | 只有 trust 一个数 |

**这些不是遗漏，是取舍。** 每加一项，抽取器就要多抽一个维度，错误率就上升一次。

## 五、如果要更接近成熟方案

按性价比排序：

| 优先级 | 补什么 | 成本 | 收益 |
|---|---|---|---|
| 1 | **Coping 策略分类**（问题聚焦/情绪聚焦/回避） | 低 | 高——能区分"硬扛"和"逃避" |
| 2 | **需求缺口的具体来源**（不只是数值低） | 中 | 中——能说清"为什么烦" |
| 3 | 22 种 OCC 完整映射 | 中 | 低——对话里用不上 |
| 4 | 多角色关系图 | 高 | 中——群聊场景才需要 |

**建议只补第 1 项。** Coping 策略是"她怎么应对"的核心，现在只有 K 一个标量，太粗。
