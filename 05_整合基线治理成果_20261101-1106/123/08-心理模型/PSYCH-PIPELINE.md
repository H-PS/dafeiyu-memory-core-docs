## 零、一句话

**情绪是状态，不是标签；注意力是情绪的输出；记忆按注意力给东西。**

三层一体，全部可计算、可审计、可回滚。

## 二、五个核心数值

| 变量 | 范围 | 含义 | 来源 |
|---|---|---|---|
| **P** 愉悦 | [−1, 1] | 好受 / 难受 | Mehrabian 1974 |
| **A** 唤醒 | [0, 1] | 激活 / 平静 | 同上 |
| **D** 支配 | [−1, 1] | 掌控 / 被压制 | 同上 |
| **E** 精力 | [0, 1] | 还能不能做需要耐心的事 | 本方案 |
| **L** 负荷 | [0, 1] | 稳态负荷，扭曲评估 | McEwen |

**为什么是这五个**：

- PAD 三个就能分出 8 个情绪族（愤怒/恐惧/悲伤/羞耻各在不同象限）
- E 和 L 让情绪**有代价**——不会累、不会积压的状态是假的
- 再多就是装饰

## 三、三层时间常数

| 层 | τ | 作用 | 上限 |
|---|---:|---|---:|
| **emo** 情绪 | 25 min | 这一下的热度 | **±0.65** |
| **mood** 心境 | 240 min | 今天整体顺不顺 | ±0.8 |
| **base** 基线 | 不衰减 | 这个人本来就偏沉/外放 | ±0.5 |

### 关键机制：溢出转心境

```
emo 到顶（0.65）→ 多出来的量 × 0.15 → 渗进 mood
```

**这是「今天真是糟透了」的形成机制。**

没有它，情绪层到顶后模型就"免疫"了，重复刺激完全无效。

实测：

| 连击次数 | emo | mood | P |
|---:|---:|---:|---:|
| 1 | −0.55 | 0.00 | −0.55 |
| 3 | −0.65 | −0.12 | −0.77 |
| 6 | −0.65 | −0.28 | −0.93 |
| 10 | −0.65 | −0.42 | −1.00 |

**8 次才到顶**，而不是 2 次。

## 四、评估：五闸门 + 状态扭曲

### 4.1 五个闸门

```
R 相关性   [0,1]    这事跟我有关吗
C 一致性   [-1,1]   促进还是阻碍
G 归因     {self, other, situation}
K 应对     [0,1]    我能做点什么吗
N 规范     [-1,1]   符合标准吗
O 确定性   [0,1]    已确定还是悬着
```

### 4.2 状态扭曲（本方案唯一的原创增量）

```js
R' = 1 − (1−R)(1 − 0.5·L)      // 阈值下降
C' = C·(1 + 0.6·L)  若 C<0     // 负性放大
C' = C·(1 − 0.3·L)  若 C>0     // 正性钝化
K' = K·(1 − 0.45·L)            // 应对感削弱
```

**实测**：

| L | 同一件小事的 \|ΔP\| |
|---:|---:|
| 0.1 | 0.064 |
| 0.9 | **0.155** |

**差 2.4 倍。** 这是「不是对方变了，是你的阈值变了」的可计算版本。

### 4.3 ΔA 必须分四支

| 情形 | 结果 |
|---|---|
| 负性 + 悬着（O<0.5） | **焦虑/恐惧**（高唤醒） |
| 负性 + 已定 + 无力（K<0.35） | **悲伤**（去激活，ΔA 为负） |
| 负性 + 已定 + 有力 | **愤怒**（高唤醒） |
| 正性 | 喜悦/兴奋 |

**最容易漏的是"悲伤是去激活"**——大多数情绪模型只知道"坏事→唤醒上升"，永远做不出真正的消沉。

### 4.4 ΔD 必须乘应对感

```js
dd = (K−0.45)·1.20 − gSelf·0.75 + gOther·0.55·(K−0.25)
```

**归因必须乘应对感**：同样"他害的"，能反击→愤怒（D↑）；无力反击→委屈（D↓）。

少了这个乘子，"被冷落"会被误判成"愤怒"。

## 五、注意力：情绪的输出

### 5.1 四个量

```js
capacity   = 2 + 3·exp(−(A−0.45)²/0.12)      // 倒 U
breadth    = 0.25 + 0.55·|P|                  // 情绪越强，扩散越远
inhibition = 0.15 + 0.55·A                    // 唤醒越高，侧抑制越强
tunnel     = clamp((A−0.6)×2,0,1) × L         // 高唤醒 + 高负荷
```

### 5.2 容量是倒 U，不是单调

| 唤醒 | 容量 | 状态 |
|---:|---:|---|
| 0.00 | 2.55 | 困倦，装不下 |
| **0.45** | **5.00** | **峰值** |
| 0.90 | 2.55 | 隧道视野 |

**峰值在 0.45 不是 0.5**：人最专注时不是最兴奋时。

## 六、记忆检索：七步

```
候选池
  ▼ ① 时间衰减      细节没了 → 打折；faded → 过滤
  ▼ ② 干扰          相似记忆互相压（倒排索引，非 O(n²)）
  ▼ ③ 情绪一致性    同向加分，反向减分
  ▼ ④ 激活扩散      一轮，不迭代
  ▼ ⑤ 侧抑制        最像的那条压得最狠
  ▼ ⑥ 去重          近乎重复的只留一条
  ▼ ⑦ 按容量选      + 反向保底槽位
```

### 6.1 顺序为什么重要

**衰减必须在情绪一致之前**：

```
错误：情绪一致 → 衰减
  → 情绪权重已拉高分数，再乘 0.6 还是很高
  → 想不起来的记忆挤掉了还记得的
```

**去重必须在侧抑制之后**：

侧抑制是"互相压"，对称的两条压得一样多，分数还是并列。
实测：两条相似度 0.533 的记忆，侧抑制后都是 0.811——**分不出胜负**。

### 6.2 分变量衰减

| 侧面 | 半衰期 | 含义 |
|---|---:|---|
| **detail** 细节 | 12 天 | 具体画面 |
| **affect** 情绪 | 60 天 | 想起还是会难受 |
| **meaning** 意义 | 900 天 | 这件事对我很重要 |

实测（冲突事件）：

| 天数 | 细节 | 情绪 | 意义 | 保真度 |
|---:|---:|---:|---:|---|
| 7 | 0.76 | 0.87 | 0.85 | full |
| 30 | 0.32 | 0.78 | 0.85 | **gist** |
| 90 | 0.03 | 0.59 | 0.84 | **trace** |
| 365 | 0.00 | 0.17 | 0.79 | trace |

**这是「细节模糊了，但那件事依然重要」的数学版本。**

### 6.3 保真度决定措辞

```
full    「那天在海边，她说要走了」
gist    「那天在海边…」——只记得大概，细节想不清了
trace   有件事，但想不起来具体了（不是忘了，是一时够不着）
faded   （不提）
```

**不能把"记得大概"说成"记得"**——模型会照着措辞演。

### 6.4 自我安抚槽位

极端情绪下（|P|>0.6 且容量≥3），强制保留一条反向记忆。

| P | 选中 | 平均效价 |
|---:|---|---:|
| −1.0 | `−−−−+` | −0.50 |
| +1.0 | `++++−` | +0.44 |

**再难受的人也会想起一点好事来安慰自己。**

## 七、顶点 / 未接住

**情绪冲到顶点却没被回应 → 记账，永久改变这个人。**

```
触发：neg 且 intensity ≥ 0.6 且 emotionIntensity ≥ 0.66
超时：顶点挂 30 分钟没被接住
后果：unmet+1，peakTrait+0.01，peakSens+0.25，base.P−0.02
```

### 触发条件（实测边界）

| 事件间隔 | 到顶点 |
|---|---|
| 3 分钟 | 第 **3** 次 |
| 10 分钟 | 第 **4** 次 |
| 25 分钟 | **不触发** |
| 60 分钟 | **不触发** |

> **崩溃从来不是一天挨一句，是十分钟里挨三句。**

### 回应的四级判定

| 判定 | 例子 | 效果 |
|---|---|---|
| **catch** 接住 | "对不起，话说重了" | 顶点清零、P 回升、trust↑ |
| **deflect** 转移 | "对了你吃饭了吗" | 顶点继续挂着 |
| **ignore** 忽略 | "嗯" "在忙" | 什么都不发生 |
| **invalidate** 否定 | "你想多了" | **比沉默更糟** |

**否定 > 沉默**——这是关系修复的头号杀手。

实测：

| 回应 | ΔP | Δtrust | Δrel | ΔL | Δtrait |
|---|---:|---:|---:|---:|---:|
| （沉默） | 0 | 0 | 0 | 0 | 0 |
| "对不起" | **+0.09** | +0.036 | +0.044 | 0 | 0 |
| "你想多了" | 0 | **−0.060** | **−0.100** | **+0.060** | **+0.020** |

### 感知折扣

```js
quality = max(0.6, 1 − 0.5·(1 − relatedness))
```

防御强的人收不到好意，但有地板——**再糟也能收到一部分**，防止死循环。

## 八、人格先行

### 三层保证

1. **输出修饰语，不输出身份语**
   ```
   好：「此刻：心情偏沉。倾向：话会变短。」
   坏：「你是一个冷漠的人。」
   ```

2. **只决定「长度、语气、是否展开」**，不决定「说什么」

3. **温度系数独立于人格**
   ```js
   finalTemp = personaBaseTemp × mind.temperature()
   ```
   疲惫直接降采样温度，不需要模型"表演"累。

### 接进 prompt 的比例

```
人格 300 字 : 此刻 50 字
```

**如果状态比人格长，模型就会开始演状态。**

## 十、性能

| 规模 | focus() 耗时 |
|---:|---:|
| 100 条 | 5 ms |
| 1,000 条 | 47 ms |
| 5,000 条 | 204 ms |
| 10,000 条 | 251 ms |
| 50,000 条 | 984 ms |

**单次事件**：`say()` 6.5μs，`extractEvent` 6.5μs。

### 关键优化

干扰检测原本是 O(n²)，5000 条要 9 秒。改成**倒排索引**：

```
bigram → [条目下标]
只比较"共享 ≥3 个 bigram"的配对
```

**5000 条：9000ms → 204ms（44 倍）。**

## 十四、怎么开始用

### 最小接入

```js
import { createPipeline } from './pipeline.mjs'

const pipe = createPipeline({ trust: 0.6 })

const ctx = pipe.receive('你怎么这么蠢')
const prompt = ctx.assemble({
  persona: '你是阿岚。说话直接，不爱绕弯。',
  memory: '· 上周他答应陪你看电影，后来没去',
})

const reply = await callLLM(prompt, {
  temperature: baseTemp * ctx.temperature,
})
```

### 三行核心

```js
mind.say(text)      // 他说了什么
mind.tick(minutes)  // 时间流逝
mind.hint()         // 给 LLM 的状态
```

## 十五、设计原则（给未来的自己）

1. **情绪是状态，不是标签** —— 标签只能是读出结果
2. **评估要被状态扭曲** —— 这是唯一原创的增量
3. **注意力是情绪的输出** —— 不是检索的优化层
4. **衰减不是可选项** —— 不衰减的记忆等于数据库
5. **沉默比否定轻** —— invalidation 必须单独建模
6. **人格永远优先** —— 情绪只修饰，不覆盖
7. **每个参数都要有场景能证明它有效** —— 否则删掉
8. **改动前先快照** —— 这个项目迭代太快

---

*这份方案的核心不是"让 AI 更像人"，而是让"像人"这件事变得可计算、可调、可回滚。*
