## 二、现在的完整链路

```
候选池
  │
  ▼ ① 时间衰减（decay.mjs）
  │    细节没了 → 分数打折
  │    彻底 faded → 直接过滤
  │
  ▼ ② 干扰（interference theory）
  │    相似记忆越多 → 互相压
  │
  ▼ ③ 情绪一致性
  │    同向加分，反向减分
  │
  ▼ ④ 激活扩散（一轮）
  │
  ▼ ⑤ 侧抑制
  │
  ▼ ⑥ 去重  ← 新增
  │    近乎重复的只留一条
  │
  ▼ ⑦ 按容量选
  │
最终结果 + fuzzy 计数
```

---

## 三、每一步为什么必须在这个位置

### ① 衰减必须在最前

**如果衰减在情绪一致之后**，一条细节早就没了的记忆会因为"情绪对得上"被完整调出来。

```
错误顺序：情绪一致 → 衰减
  → 情绪权重已经把分数拉高，再乘个 0.6 还是很高
  → 结果：想不起来的记忆挤掉了还记得的

正确顺序：衰减 → 情绪一致
  → 先按"还能不能想起"筛一遍，再谈"想不想得起"
```

### ② 干扰在情绪一致之前

干扰是**乘在分数上**的惩罚。如果放在情绪加权之后，同向记忆被抬高的分会被干扰压掉一部分，两个效应互相抵消。

### ③ 去重必须在侧抑制之后

这是实测发现的：

```
id1: 他答应陪我看电影，后来没去      score=1.014
id2: 他答应陪我看电影，结果又没去    score=1.014
```

**侧抑制把两条都压到 0.811——压得一样多，还是并列。**

因为侧抑制是"互相压"，对称的两条互相压的量相等。**对称的重复项无法分出胜负。**

所以必须显式去重：按分数降序扫，相似度超阈值的跳过。

## 四、实测数据

### 衰减接入的效果

| 记忆 | 年龄 | 分数 | 保真度 |
|---|---:|---:|---|
| 他答应陪我看电影，后来没去 | 1 天 | **0.956** | full |
| 我们聊到凌晨三点 | 30 天 | **0.483** | gist |
| 他记得我不吃香菜 | 400 天 | **过滤** | faded |

**30 天前的记忆分数只剩一半，400 天前的直接不参与竞争。**

### 干扰接入的效果

```
id1 (0 条相似) → 乘子 1.00
id1/id2 (互相似) → 乘子 0.70
```

### 去重接入的效果

```
去重前：id1, id2, id4   （id1/id2 是同一件事）
去重后：id1, id4
```

### fuzzy 计数

```
fuzzy=1   → hint 里出现「有 1 件事你知道存在，但一时想不起具体」
```

## 五、保真度如何影响分数

```js
detail >= 0.5                    → ×1.00   能讲清楚
detail >= 0.18                   → ×0.85   只记得大概
affect >= 0.25 || meaning >= 0.35 → ×0.60   只剩"有这件事"
否则                              → ×0.25   彻底淡了（随后被过滤）
```

**注意：情绪残留不能把 faded 救回来。**

测试过：`detail=0.02, affect=0.9` 判为 `trace` 而不是 `gist`。
因为"只剩情绪、没有细节"是**想不起具体**，不是**记得大概**。

## 七、接入方式

### 基本用法

```js
import { focus } from './attention.mjs'

const r = focus(pool, mind.state, mind.params, { now: Date.now() })

r.picked    // 选中的记忆
r.fuzzy     // 想不起来的条数
r.attention // 注意力参数
```

### 关掉某一环（调试用）

```js
focus(pool, st, p, { decay: false })     // 不衰减
focus(pool, st, p, { similar: false })   // 不算干扰
focus(pool, st, p, { dedupeThreshold: 0.7 })  // 去重更宽松
```

### 接进管线

```js
const recall = focus(pool, pipe.state, pipe.params)
const ctx = pipe.receive(text)
ctx.assemble({
  persona,
  memory: formatMemories(recall.picked),
  // fuzzy 会自动进 hint
})
```

**注意：`compose` 现在接受 `{ recall }`**，管线不自己调检索（那需要向量库）。

## 九、已知限制

| 限制 | 影响 | 补救 |
|---|---|---|
| 相似度是字符二元组 | "放我鸽子"和"没去"匹配不上 | 接向量库后换成余弦 |
| 干扰阈值 0.5 是手调 | 可能过严或过松 | 按真实语料调 |
| 去重按分数保留 | 可能丢掉信息更全的那条 | 可改成"保留更长的文本" |
| 没有"再巩固"闭环 | 回忆后 detail 不会回升 | `reinforce()` 已实现，未接入 |

### 最后一条值得说

`decay.mjs` 里的 `reinforce()` 实现了"回忆会强化记忆"，但**没有接进 `focus()`**。

原因：`focus()` 是纯函数（不该有副作用），而再巩固需要写回记忆。

**正确做法**：调用方拿到 `r.picked` 之后，自己调 `reinforce()` 更新库。

```js
const r = focus(pool, st, p)
for (const m of r.picked) {
  const updated = reinforce(m, decayState(m, ageDays(m)), { now: Date.now() })
  db.upsert(updated)
}
```
