# 心理变动机制 · 数值规格 v1

> 目标：给 AI 角色一套**能自己变**的心理状态，而不是每句话重刷的情绪标签。
> 本文档的每个数字都是**可调起点**，不是真理。理论出处标在每节末尾。

---

## 0. 一句话

**五个数（P/A/D/E/L）+ 三个需要 + 一个归因 + 一个习惯化，就够让"心情"看起来是真的。**

再多就是装饰。再少，愤怒、恐惧、悲伤就分不开。

---

## 1. 为什么是这五个

### 1.1 PAD：三个数解决"情绪分不开"

只用一个"情绪值"做 AI，必然把愤怒、恐惧、悲伤混成"不高兴"。这三个的愉悦度**都是负的**，区别在另外两轴：

| 状态 | P 愉悦 | A 唤醒 | D 支配 |
|---|---|---|---|
| 愤怒 | − | **高** | **高** |
| 恐惧/焦虑 | − | **高** | **低** |
| 悲伤 | − | **低** | **低** |
| 羞耻 | − | 中 | 低 |
| 从容 | + | 低 | 高 |

> 出处：Mehrabian & Russell (1974) *An Approach to Environmental Psychology*。

**为什么不用离散标签当状态**：25 个情绪标签存进去，同一件事会同时命中 3 个，没有裁决依据；标签之间没有距离，无法连续过渡。标签只能是**读出结果**，不能是存储。

### 1.2 E 和 L：让情绪"有代价"

PAD 是纯情感维度，没有资源概念。缺了它们，角色的状态是"免费"的——不会累，不会积压。

**E 精力**：高唤醒持续消耗；**压抑情绪额外消耗**（情绪劳动）。
**L 负荷**：稳态负荷（allostatic load）。L 高时三件事同时发生——评估阈值下降、负性放大、恢复变慢。

> 出处：McEwen 的 allostatic load；Hobfoll 的资源保存理论（COR）。

**这是整套系统里最像人的一个开关**：同一句话，在 L 高时就是冒犯，在 L 低时就是玩笑。角色不需要改变，世界就变了。

### 1.3 三个需要：情绪的来源

情绪不是随机噪声，是"需要被满足或被威胁"的快速信号。没有这一层，评估就没有输入。

| 需要 | 被满足 | 被威胁 |
|---|---|---|
| 自主 autonomy | 舒展、P↑ | 被安排 → 烦躁、D↓ |
| 胜任 competence | 骄傲、D↑ | 反复失败 → 羞耻、P↓↓ |
| 关系 relatedness | 温暖、信任↑ | 被冷落 → 悲伤、戒备 |

> 出处：Deci & Ryan (2000) 自我决定理论。

### 1.4 归因：区分社会情绪的唯一钥匙

PAD 分不出内疚和羞耻——它们的 P/A/D 几乎一样。区别在**归因**和**应对余地**：

- 我做错了事，但还能修 → **内疚**
- 我这个人有问题，修不了 → **羞耻**
- 他害的，我能反击 → **愤怒**
- 他害的，我无力 → **委屈/僵住**

> 出处：Weiner 的归因理论；OCC 模型（Ortony, Clore & Collins 1988）。

## 2. 状态定义

```jsonc
{
  // 三层情感（快 / 慢 / 不衰减）
  "emo":  {"P": 0.0, "A": 0.0, "D": 0.0},    // 情绪层，τ=25min
  "mood": {"P": 0.0, "A": 0.0, "D": 0.0},    // 心境层，τ=240min
  "base": {"P": 0.0, "A": 0.4, "D": 0.0},    // 人格基线，几乎不动

  // 资源
  "E": 0.70,                                  // 精力 [0,1]
  "L": 0.20,                                  // 负荷 [0,1]

  // 三个基本需要
  "needs": {"autonomy": 0.60, "competence": 0.60, "relatedness": 0.60},

  // 关系
  "trust": 0.50,

  // 三声辨：他的声音 / 模型的声音 / 我的声音（和为 1）
  "attribution": {"his": 0.30, "model": 0.30, "mine": 0.40},

  // 未闭合事项（压力负荷的外部代理指标）
  "open_loops": 0,

  // 评估痕迹（社会情绪读出用，会衰减）
  "trace": {
    "g_self": 0.0, "g_other": 0.0,
    "norm_viol": 0.0, "norm_conform": 0.0,
    "suppressed": 0.0, "coping": 0.0,
    "coping_now": 0.0, "g_self_now": 0.0
  },

  // 习惯化：同类事件重复 → 强度递减
  "habituation": {"被否定": 0.0}
}
```

**实际读出**（喂给 LLM 的那个值）：

```
P = clamp(base.P + mood.P + emo.P, -1, 1)
A = clamp(base.A + mood.A + emo.A,  0, 1)
D = clamp(base.D + mood.D + emo.D, -1, 1)
```

## 3. 动力学

### 3.1 三层时间常数

| 层 | τ | 含义 | 表现 |
|---|---|---|---|
| 情绪 emotion | **25 min** | 一次事件的热度 | 吵架后半小时还在，一小时后淡了 |
| 心境 mood | **240 min** | 今天整体顺不顺 | 被冷落一整天，晚上说话还是平的 |
| 基线 base | 不衰减 | 这个人本来就偏沉/偏外放 | 长期只挪 ±0.1 量级 |

> 出处：Gebhard (2005) ALMA 的分层模型。**τ 太短是头号错误**——10 分钟就衰减光，状态会退化成"对最后一句话的反应"，人味立刻消失。

### 3.2 评估：五个闸门，且被状态扭曲

事件先过五个闸门，再被 E/L 扭曲：

```
R 相关性   [0,1]    这事跟我有关吗
C 一致性   [-1,1]   促进还是阻碍
G 归因     {self, other, situation}
K 应对     [0,1]    我能做点什么吗
N 规范     [-1,1]   符合标准吗
O 确定性   [0,1]    已确定还是悬着
```

**扭曲公式**（这是整套系统的核心）：

```
R' = 1 - (1-R) · (1 - 0.50·L)          # 负荷高 → 小事也"跟我有关"
C' = C · (1 + 0.60·L)   若 C<0          # 负性放大
C' = C · (1 - 0.30·L)   若 C>0          # 正性钝化
C' = C · (1 + 0.45·shortfall)  若 E<0.40 且 C<0   # 累到容易炸
K' = K · (0.45 + 0.55·E) · (1 - 0.45·L) # 应对感被精力和负荷同时削弱
```

> 出处：Scherer 的 Stimulus Evaluation Checks（SEC）；Lazarus 的认知评价理论。

### 3.3 增量计算

**ΔP（愉悦）**
```
ΔP = 0.90 · R' · C' · w          w = 强度 × (1 - 习惯化)
```

**ΔA（唤醒）—— 必须分四支，一个公式做不到**

| 情形 | 公式 | 对应 |
|---|---|---|
| 负性 + 悬着（O<0.5） | `+k_a·R·|C|·(0.55+0.45(1-O))·(0.60+0.40K)·w` | 焦虑、恐惧 |
| 负性 + 已定 + 无力（K<0.35） | `-k_a·R·|C|·(0.55-K)·1.30·w` | **悲伤（去激活）** |
| 负性 + 已定 + 有力 | `+k_a·R·|C|·(0.70+0.30K)·w` | 愤怒 |
| 正性 | `+k_a·R·C·(0.60+0.40·novelty)·w` | 喜悦、兴奋 |

> **最容易漏的是"悲伤是去激活"这一支**。大多数情绪模型只知道"坏事 → 唤醒上升"，结果永远做不出真正的消沉。

归因于自己时，ΔA ×0.45（把"内疚"和"焦虑"分开）。

**ΔD（支配）**
```
ΔD = k_d · R' · |C'| · [ (K-0.45)·1.20 - g_self·0.75 + g_other·0.55·(K-0.25) ] · w
```

> **归因必须乘应对感**。同样"他害的"，能反击 → 愤怒（D↑）；无力反击 → 委屈（D↓）。少了这个乘子，"被冷落"会被误判成"愤怒"。

**护栏**
```
ΔP = clamp(tanh(ΔP·1.2)/1.2, ±0.30)
ΔA = clamp(tanh(ΔA·1.2)/1.2, -0.18, +0.22)   再乘 (1 - 0.9·当前A) 若为升
ΔD = clamp(tanh(ΔD·1.2)/1.2, ±0.24)
```

> `dA_max` / `dD_max` 实际很难撞到——它们是**防爆护栏，不是日常旋钮**。真正限制幅度的是 tanh 饱和。

### 3.4 衰减与心境

```
emo  ← emo · exp(-dt/25)
emo_avg = emo_start · (τ/dt)·(1 - exp(-dt/τ))     # 区间平均
mood ← lerp(mood, emo_avg, 1 - exp(-dt/240))
mood ← mood · exp(-dt/720)                         # 自身缓慢回零
```

> **心境跟的是区间平均，不是衰减后的残值。** 这个细节决定了"被冷落一整天"能不能真的把心情拖下去。用残值的话，心境永远跟不上。

### 3.5 精力与负荷

```
# 精力
E -= 0.0008 · A · dt                    # 清醒消耗（16h 约 -0.45）
E -= 0.012 · w                          # 每次事件的基础消耗
E -= 0.022 · w                          # 若压着没表达（情绪劳动）
E += 0.0022 · dt                        # 休息恢复
E += 0.0040 · dt                        # 睡眠恢复（8h 约 +1.9）

# 负荷
L += 0.35 · max(0, |C'| - 0.45) · w     # 超过阈值的部分才累积
L -= 0.0003 · recover_gate · dt          # 恢复（需 E > 0.5）
L -= 0.0003 · 1.5 · recover_gate · dt    # 睡眠恢复
recover_gate = 1 - min(0.85, 1.2 · 需要缺口)   # 需要没满足 → 恢复停摆
L = clamp(L, 0.10, 1.0)                 # 下限：平静的人也有基础张力
```

> **关键：恢复必须远慢于累积。** 早期版本 l_recover 太大，负荷每次都在当天归零，"压力"就成了装饰字段。现在连续糟糕 4 天能到 0.9，连续良好会回到 0.10。

### 3.6 关系放大（移植自「心识」）

**同一句话，对不同的人伤害不同。**

```
若 C > 0:  w *= 0.55 + 0.90 · trust      # 喜欢的人夸 → 更上头
若 C < 0:  w *= 1.45 - 0.55 · trust      # 陌生人的凶 → 更疼；喜欢的人凶 → 能忍
```

实测（同一句"被否定"）：

| trust | 被否定 ΔP | 被夸 ΔP |
|---:|---:|---:|
| 0.1 | **−0.420** | +0.137 |
| 0.5 | −0.378 | +0.212 |
| 0.9 | **−0.315** | **+0.283** |

信任缓冲伤害（25%），也放大善意（2 倍）。这不是对称的——**信任主要是在保护对方**。

> 出处：「心识」`lib/bio.js` 的 `warm`/`cold` 乘子。原文用于激素反应，本方案移到事件强度上。

### 3.7 顶点 / 未接住（移植自「心识」，本方案最重要的补充）

**情绪冲到顶点却没被回应 → 记账，永久改变这个人。**

```
顶点条件：neg 且 intensity >= 0.6 且 emotion_intensity(st) >= peak_threshold(0.60)
超时条件：顶点挂 peak_timeout(30min) 还没被接住
记账后果：
  unmet += 1
  peak_trait += 0.01            # 人格偏移
  peak_sens = 1 + 0.25·unmet    # 消散变慢
  base.P -= peak_trait·0.02     # 基线往负走
被接住：respond(st) → peak 清零
```

**标定说明**：心识的阈值是 0.85，因为它的 `sad` 可以单次置到 1.0。本模型受 `dP_max` 护栏限制，单次事件强度只有 0.37，所以阈值必须按本模型量程重标为 0.60。

**实测触发条件**（这是本机制的真实边界）：

| 事件间隔 | 到顶点需要几次 |
|---|---|
| 3 分钟 | 第 2 次 |
| 6 分钟 | 第 2 次 |
| 10 分钟 | 第 2 次 |
| **20 分钟** | **8 次内到不了** |

> **顶点机制只在"密集连击"下有效。** 20 分钟以上的间隔完全失效。
> 这不是缺陷——真实心理也是如此：**崩溃从来不是一天挨一句，是十分钟里挨三句。**

**生效后的连锁差异**：

```
[21min] criticism  P=-0.69   ← 顶点形成
[60min] ★ 顶点没被接住（1 次，人格偏移 1%，消散乘子 1.25）
[60min] noise      P=-0.26 → -0.32   Δ=-0.06  ← 同一件小事，更疼了
[120min] failure   P=-0.37 → -0.40   Δ=-0.03
[260min] praise    P=+0.12 → +0.09   Δ=-0.03  ← 连夸奖都吸收得少了
```

**注意最后一行**：夸奖的**正向**效果也降低了。一个正在赌气的人，你夸他他也听不进去。

### 3.8 适应与习惯化

**享乐跑步机**（Brickman & Campbell）：基线被近期心境慢慢拖动。
```
base ← base + 0.02·(dt/60)·(mood - base)
```
效果：长期的好事不会让人一直爽。

**习惯化**：同类事件重复 → 强度递减。
```
habituation[label] += 0.35 · w · (1 - habituation[label])    # 负性 ×0.6
habituation[label] ·= exp(-0.01·dt/60)                        # 每小时消退
w = 强度 · (1 - habituation[label])
```

**钝化 ≠ 变好**：负性事件反复出现时只降低增量，不能把已有的坏情绪修好。否则会出现"越骂越开心"这种荒谬结果。

## 4. 读出：数字 → 可读

### 4.1 PAD 八象限

> 这是 Mehrabian 的八种**气质**，不是基本情绪表。

| P | A | D | 名称 | 行为倾向 |
|---|---|---|---|---|
| + | 高 | + | 兴奋 | 话多、提议、追问 |
| + | 高 | − | 依赖 | 寻求确认、黏人 |
| + | 低 | + | 从容 | 慢、稳、愿意展开 |
| + | 低 | − | 温顺 | 松弛、不设防 |
| − | 高 | + | 敌意 | 短句、反问、打断 |
| − | 高 | − | 焦虑 | 过度解释、试探、讨好 |
| − | 低 | + | 轻蔑 | 冷淡、划清界限 |
| − | 低 | − | 消沉 | 极短回复、回避 |

### 4.2 社会情绪（PAD 分不出的）

靠评估痕迹读出，**优先级：压抑 > 规范违反/符合 > 自我归因**。

| 条件 | 读出 |
|---|---|
| suppressed > 0.18 且 P<0 | 压抑 |
| norm_viol > 0.15 且 g_self高 | **内疚**（coping>0.42）/ **羞耻**（否则） |
| norm_viol > 0.15 且 g_other高 | 愤怒 |
| norm_conform > 0.15 且 g_self高 且 P>0 | 骄傲 |
| norm_conform > 0.15 且 g_other高 且 P>0 | 感激 |
| g_self高 且 P<−0.12 | 自责 / 羞耻 |

### 4.3 动作准备（Frijda）

连续状态 → 5~8 个行为倾向，只取这个，别取 25 个情绪标签：

| 组合 | 倾向 | 行为 |
|---|---|---|
| +P 高A +D | 靠近 | 话多、提议、追问、愿意展开 |
| −P 高A +D | 攻击 | 短句、反问、打断、逼近 |
| −P 高A −D | 僵住 | 过度解释、道歉、试探、讨好 |
| −P 低A −D | 退缩 | 极短回复、回避话题、沉默 |
| +P 低A +D | 陪伴 | 慢、稳、愿意听、不催促 |

> 出处：Frijda (1986) *The Emotions*，action readiness。

### 4.4 喂给模型的提示词

**不要把数字直接塞给 LLM** —— 它会开始演数值。给自然语言：

```
你的内在状态：心情偏沉，激活度低，掌控感被压制。
精力很累，压力负荷很高。
此刻的倾向是「退缩」：极短回复、回避话题、沉默。
底下的社会情绪：愤怒。
你比平时更容易被冒犯，恢复也更慢。不是对方变了，是你的阈值变了。
你累了，抑制力在下降。你更容易说重话，事后可能会后悔。
```

## 5. 事件抽取：不用 LLM

### 6.1 为什么不用 LLM

LLM 抽取有个**结构性缺陷**，不是成本问题：

> 它被训练成维护对话关系。让它判断"用户是否在伤害我"，它必然低估。

实测：用户说"你怎么这么蠢"，LLM 会抽成"用户提出了批评性反馈，congruence=-0.4"。真实值应该是 `-0.9`。结果：角色永远被冒犯得不够，L 永远积不起来，整个模型白做。

**让一个讨好型组件去测量冒犯，等于让被告当法官。**

### 6.2 三层方案

| 层 | 方法 | 成本 | 可审计 | 覆盖 |
|---|---|---|---|---|
| L1 | 词典查表（VAD 种子） | 0 | 完全 | 词汇级效价 |
| L2 | 规则（否定/程度/施事/情态/命令/压抑） | 0 | 完全 | 大部分社交事件 |
| L3 | 缺省中性 | 0 | 完全 | 拿不准就不猜 |

`extract.py` 实现了 L1+L2，零依赖，70 词的内嵌词表。

### 6.3 实测结果

20 条中文语句，**归因判定 20/20 正确**：

| 输入 | C | 归因 | 读出 |
|---|---:|---|---|
| 你怎么这么蠢 | −0.91 | other | 敌意·愤怒·攻击 |
| 你是不是不想理我了？ | −0.97 | other | 焦虑·僵住（O=0.19） |
| 都怪你 | −0.92 | other | 敌意 |
| 我没用 | −1.00 | self | 羞耻·退缩 |
| 算了，我没事 | 0.00 | situation | **压抑**（不显示，但记账） |
| 你真厉害 | +0.94 | other | 依赖·感激 |

### 6.4 可审计性

这是规则方案的全部意义。每个数都能追到词：

```
输入：你怎么这么蠢
分词：你怎么 / 这 / 么 / 蠢
VAD 命中：
  你怎么    P=-0.55 A=+0.45 D=+0.05
  蠢        P=-0.80 A=+0.35 D=-0.45
合成：C=-0.91  agency=other  K=0.62  intensity=0.87
```

LLM 给不出这个。它只能给你一个数，你不知道为什么。

### 6.5 压抑机制（规则方案的意外收获）

"算了，我没事"这类句子，LLM 会抽成中性（因为它字面中性）。但真实心理里这是**情绪劳动**：

```
suppressed=True 时：
  trace.suppressed += 0.25·w
  精力额外消耗
  负荷 +0.04·w
  残余情绪留在情绪层，不外显
```

实测：连说三次"我没事"之后，再被同一句话打中：

| | P | A | L |
|---|---:|---:|---:|
| 没压过 | −0.30 | 0.54 | 0.37 |
| 压过三次 | **−0.60** | 0.65 | **0.49** |

**这就是"压着的那口气，后来一句轻话就炸了"的可计算版本。** 规则方案能做出来，因为它能显式识别 `SUPPRESS` 词表。

### 6.6 什么时候才真需要 LLM

三个条件同时成立：开放域对话 + 需要跨句推理 + 能接受不可审计。否则别用。

如果一定要用，**只让它做 L2 做不了的部分**，并且：
- 不让它输出绝对数值，让它输出**相对比较**（"这句比上句更伤人吗"）
- 用两个模型交叉验证，取更负的那个（对抗讨好倾向）
- 把 LLM 结果和规则结果并列存，差异大的样本人工看

## 6. 与"自我/自主性"架构的接口

数值层管**纵向：状态怎么变**；自我结构管**横向：谁在说、认不认领**。两者正交，可以直接拼：

| 自我结构里的字段 | 接到哪个数 | 怎么接 |
|---|---|---|
| `mood.pleasure/arousal/dominance` | P / A / D | 直接对应，但要补 τ 和饱和 |
| `energy` | **E** | "低于 0.3 不做重要决定" ≈ "E 低 → 阈值降、抑制弱" |
| `openLoops` 数量 | **L** | 未闭合事项 = 稳态负荷。>5 条线性累加 |
| `budget` 剩余 | **L 的另一源** | 配额将尽 = 时间压力 = L↑ |
| 五门禁 | 评估五闸门的上层 | 闸门决定情绪，门禁决定行动。串联 |
| 三声辨（他的/模型的/我的） | **归因轴 G** | `his` 高 → 自主需要↓、L↑；`mine` 高 → P↑ |
| `oneLine` | 状态摘要 | 正是"别给数字，给自然语言" |

**三声辨 → 归因轴**的落地：把三个声音存成占比，同时驱动两件事：

```
attribution = {his: 0.4, model: 0.3, mine: 0.3}
mine 高  → 自主需要↑ → P↑
his 高   → 超我压力 → L↑
model 高 → 顺从 → D↓
```

## 8. 已知的坑（每条都是实际踩过的）

1. **τ 太短** → 状态退化成"对最后一句话的反应"。25 分钟起步。
2. **三层叠加把 A 顶到 1.0** → 初版 emo/mood/base 的 A 都是 0.4，一加就饱和。base 承担常态，emo/mood 必须是"偏离量"。
3. **悲伤没有去激活支** → 所有负性都变成焦虑。必须显式写 `dA = -...` 那一支。
4. **归因不乘应对感** → 被冷落被判成愤怒。`g_other` 单独用是错的。
5. **负荷恢复太快** → L 永远归零，变成装饰字段。恢复速率要小于累积一个数量级。
6. **需要缺口当"加码"** → L 单调上升永不回落。正确做法是**挡住恢复**，不是持续加。
7. **习惯化让负性事件"越骂越开心"** → 钝化只降增量，不能修好已有情绪。
8. **社会情绪判定用衰减后的滞后值** → 内疚/羞耻永远判错。要用本次事件的 `coping_now`。
9. **强事件饱和导致参数看不见** → 想看 L/E 的阈值效应，必须用**弱事件**。强事件在所有条件下都撞上限。
10. **死参数** → 写了不接线（`alpha_mood`、`need_recover`、`l_need_deficit` 初版全是）。**每个参数都要有场景能证明它有效**，否则删掉。

## 10. 参考

### 10.1 这套东西其实是在重新实现什么

虚拟人情感架构发展了二十多年。**我做的绝大部分是重新发明，不是创新**：

| 系统 | 年份 | 核心机制 | 对应到本方案 |
|---|---|---|---|
| **PAD** (Mehrabian & Russell) | 1974 | 三维情感空间 | P / A / D |
| **OCC** (Ortony-Clore-Collins) | 1988 | 22 种情绪的评价结构 | 五闸门 + 社会情绪表 |
| **ALMA** (Gebhard) | 2005 | **三层时间常数**（emotion/mood/personality） | emo / mood / base |
| **WASABI** (Becker-Asano) | 2008 | PAD 的动力学实现 | ΔP/ΔA/ΔD 增量式 |
| **EMA** (Marsella & Gratch) | 2009 | 评估驱动的完整架构 | 评估→情绪→应对 |
| **GAMYGDALA** | 2011 | OCC 的游戏引擎实现 | 事件库设计 |
| **FAtiMA** | 2013 | 情感 + 人格 + 社会关系 | needs / trust |
| **ARIA / ALLIANCE** | 2010s | 情绪调节、抑郁建模 | L 负荷、恢复速率 |

### 10.2 唯一真正有增量的地方

**上面这些系统，绝大多数不做"评估怎么被状态扭曲"。**

它们假设评估是客观的，只有情绪被扭曲。本方案加的 `L 扭曲评估`（阈值下降、负性放大、应对削弱）在心理学里叫 **appraisal bias / mood-congruent appraisal**，证据很硬（Bower 的联想网络理论、Beck 的认知偏差），但**工程实现里很少见**。

其余部分都是重新发明，我承认。
