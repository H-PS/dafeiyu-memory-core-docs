# 工作区里别人方案的情绪实现：价值评估

## 结论先行

**有价值，但不在"数值"上，在三个本模型没有的机制上。**

两套方案：
- **《没有卡的鱼》(柠月)** — 只有研究笔记，无源码
- **《心识》(deploy-kit)** — 有完整源码，`lib/bio.js` + `deploy-mind.mjs`

我做了实际移植实验（`port_xinshi.py`），结论见后。

## 一、心识（deploy-kit）：真东西在哪

### 1.1 生物层：19 个激素/递质变量

`lib/bio.js` 实现了褪黑素、腺苷、皮质醇、血糖、催产素、体温、疼痛、交感/副交感、加压素、饥饿、水分、免疫、多巴胺、血清素、去甲肾上腺素、肾上腺素。

**这不是"数值多"，是有真实生理模型支撑的：**

```js
// 时间漂移：不管聊不聊天，身体一直在变
b.melatonin = 朝 0.8 或 0.12 走（按昼夜）
b.adenosine = 醒着 +0.08/h，睡着 -0.12/h
b.cortisol  = 自然 -0.02/h；>0.55 时 HPA 负反馈压制自己
b.dopamine/serotonin/noradrenaline = 往基线走，半衰期 0.45~0.75h
```

**HPA 负反馈那一行是全文最专业的**：皮质醇高会压自己，不会无限升。这是内分泌学的基本事实，绝大多数游戏情绪系统都没有。

### 1.2 事件驱动：同一个事件，对不同的人反应不一样

```js
const warm = 0.55 + aff * 0.9 + love * 0.6;   // 喜欢的人夸 → 更上头
const cold = 1.45 - aff * 0.55 - love * 0.35; // 喜欢的人凶 → 能忍
```

**这是本模型完全没有的维度**：我有 `trust`，但它只影响"是否归因于他者"，不影响事件强度的放大/缩小。

这一条极有价值：**同样一句"你怎么这么蠢"，陌生人说是伤害，喜欢的人说是撒娇。** 我的模型现在两者一样疼。

### 1.3 派生层：从激素算出情绪倾向

```js
energy      = 0.20 + 0.50*NA + 0.25*ADR + 0.10*DA - 0.14*C - 0.45*MEL - 0.22*max(0,ADEN-0.45)
valence     = 0.12 + 0.30*(DA-0.5) + 0.22*(S-0.65) - 0.28*(C-0.2) - 0.10*max(0,ADR-0.2)
irritability= 0.08 + 0.9*(C-0.2) - 0.2*(S-0.65) + 0.30*max(0,(0.35-GLU)/0.35) + ... + 0.30*max(0,hunger-0.5)
clinginess  = 0.2 + 0.75*(OT-0.3)
```

**注意 `irritability` 的构成**：皮质醇 + 低血糖 + 高肾上腺素 + 高腺苷 + 饿。

这是"饿怒"（hangry）的可计算版本。我的模型里 `E` 低只会放大负性，不会单独产生"烦"这个状态。

### 1.4 三层情绪 + 半衰期表

```js
e.base.contentment = towards(0.5, 半衰期 24h)   // 满足留一天
e.base.calm        = towards(0.6, 半衰期 8h)
e.base.dejection   = towards(0.15, 半衰期 12h)
e.mid.joy          = towards(0.2, 半衰期 0.6h)  // 高兴几十分钟
e.mid.sad          = towards(0.12, 半衰期 1.5h) // 难过最久
e.mid.angry        = towards(0.1, 半衰期 0.6h)
```

**按情绪分别指定半衰期**，而且数值有依据（"参照情绪持续时间研究"）。

我的模型用单一 `tau_emotion=25min`，把所有情绪压成同一个速度。**这是粗糙的**：难过应该比高兴留得久。

### 1.5 顶点机制（peak / unmet）—— 最有价值的一条

```js
// 顶点没被接住 30 分钟 → 记一次
if (peak[k] >= 0.85) {
  if (now() - peakAt[k] > 30min) {
    unmet[k] += 1;
    peak[k] = 0.55;
    traits[tk] += 0.01;     // 累积成性格
  }
}
// 快速情绪越不被接住，消散越慢
const sens = 1 + 0.25 * unmet.flutter;
e.fast[k] *= pow(0.5, hrs / (0.05 * sens));
```

**这个机制本模型完全没有。** 我有：
- 习惯化（重复同类事件 → 变钝）
- 负荷 L（累积压力）

但我没有：**"情绪冲到顶点却没被回应"这个特定事件会记账，并永久改变这个人。**

而且它有 `sens` 乘子：**越不被接住，以后散得越慢。** 这是"耿耿于怀"的可计算版本。

## 二、移植实验结果

我把它移植到本模型，跑了同一段剧本。

### 2.1 移植过程本身就是发现

**第一轮：完全无效（未接住=0）。** 原因链：

1. 我的 `dP_max=0.30` 护栏让单次事件强度上限只有 **0.27**
2. 心识的顶点阈值是 **0.85**（因为它的 `sad` 可以单次置到 1.0）
3. 差距不是参数没调好，是**两种设计哲学**

| | 本模型 | 心识 |
|---|---|---|
| 单次事件能改变多少 | 最多 0.30（防跳变） | 可以直接置到 1.0 |
| 顶点阈值 | 需要重新标定 | 0.85 |
| 情绪变量 | 连续 PAD | 离散情绪，可单独置顶 |

**这是一个真实的设计冲突，不是 bug。**

### 2.2 标定后的关键数据

把阈值按本模型量程重新标定为 0.60，然后测"几次连击能到顶点"：

| 事件间隔 | 到顶点需要几次 |
|---|---|
| 3 分钟 | 第 3 次 |
| 6 分钟 | 第 3 次 |
| 10 分钟 | 第 4 次 |
| **20 分钟** | **8 次内到不了** |

**结论：顶点机制只在"密集连击"下有效。** 20 分钟以上的事件间隔，它完全失效。

这不是缺陷——真实心理也是如此。**崩溃从来不是一天挨一句，是十分钟里挨三句。**

### 2.3 生效后的差异

```
[ 21min] criticism  P=-0.69   ← 顶点形成
[ 60min] ★ 顶点没被接住（1 次，人格偏移 1%，消散乘子 1.25）
[ 60min] noise      P=-0.26 → -0.32   Δ=-0.06  ← 同一件小事，更疼了
[120min] failure    P=-0.37 → -0.40   Δ=-0.03
[180min] criticism  P=-0.36 → -0.40   Δ=-0.04
[260min] praise     P=+0.12 → +0.09   Δ=-0.03  ← 连夸奖都吸收得少了
```

**这就是"没被接住"的代价：同样的事，之后每一件都更疼，而且好的也补不回来。**

注意最后一行：夸奖的**正向**效果也降低了。这符合真实——一个正在赌气的人，你夸他他也听不进去。

## 三、柠月（没有卡的鱼）：只有笔记，但有三条工程命题

无源码，但研究笔记里这三条可以直接用：

### 3.1 温度公式——状态改采样，不改措辞

```
temperature(base) = clamp(base + boredom*0.6 + mood*0.25 - (1-energy)*0.3, 0.3, 1.4)
```

> 绝大多数系统把情绪用在**措辞层**（"你现在有点困，说话短一点"），它用在**采样层**。

**这是本方案可以立刻加的一条。** 我现在把状态转成自然语言喂给 LLM，让模型"表演"疲惫。但更硬的做法是：**直接调 temperature。**

累了 → 温度降 → 输出收敛、重复、发散度低。这不需要模型配合。

### 3.2 gaps：用标量张力场替代目标列表

```
tension 0–100，每小时 +1.5
说出来会松：最重那件 -25（不低于 45）
两件都 ≥95 时，更久没被碰的降 10
```

**本模型的 `open_loops` 只是个计数，而它是带张力的场。**

而且它天然给出一个判据：**tension 高但还没到阈值，就是"忍着不说的事"。** 这正好接上我的 `suppressed` 机制——我用词表识别压抑，它用数值。

### 3.3 scars：给删除定价

剪掉一根枝 → 生成一段接不上的残片（≤12 字）+ 一种说不清的感觉，30% 概率进念头。

和解要三条同时成立：她回去碰、敢猜那半句是什么、猜完不再怕。

**这是本方案完全没有的"记忆代价"维度。** 但它最容易退化成伤痕文学，要慎用。

## 四、诚实评估

### 4.1 应该抄的（按价值排序）

| 优先级 | 机制 | 为什么 | 成本 |
|---|---|---|---|
| **1** | **顶点/未接住 (peak/unmet)** | 本模型完全没有；产生"耿耿于怀" | 中 |
| **2** | **关系放大 (warm/cold)** | 同一句话对不同的人伤害不同 | 低 |
| **3** | **温度公式** | 绕过模型表演，直接改采样 | 极低 |
| **4** | **按情绪分别指定半衰期** | 难过该比高兴留得久 | 低 |
| **5** | **HPA 负反馈** | 皮质醇高会压自己，不会无限升 | 极低 |
| 6 | gaps 张力场 | 比 `open_loops` 计数丰富 | 中 |
| 7 | scars | 有文学野心，但易模板化 | 高 |

### 4.2 不该抄的

1. **19 个激素变量**。对本模型来说太多了。`irritability` 的 5 个构成项可以压成 1 个 `E` 的低血糖项。**变量多不等于模型好，只等于难调。**

2. **离散情绪 + 连续 PAD 双轨**。心识同时有 `mid.joy/sad/angry`（离散）和 `base.elation/dejection`（连续偏移）。两套并存，映射关系靠手写。我上一轮论证过：**离散标签只能是读出结果，不能是存储。** 它这里是反例。

3. **`c01` 到处 clamp**。它几乎所有赋值都套 `c01`（clamp 到 0-1）。这会让饱和成为默认行为，看不出哪里真的撞墙。我用 tanh 饱和 + 显式护栏，更容易诊断。

### 4.3 它的弱点

1. **没有评估层**。它是 `正则匹配关键词 → 直接改激素`：
   ```js
   if (/(吓|害怕|凶|吼|骂|滚|闭嘴)/.test(t)) { cortisol += 0.15 }
   ```
   这是**词表驱动，不是评估驱动**。它没有 R/C/G/K/N 五维，所以做不出"同一句话在不同归因下产生不同情绪"。

   **这恰好是我这套的强项，也是我唯一真正有增量的地方。**

2. **没有"评估被状态扭曲"**。它的事件反应是固定的 `+0.15`，不随当前 L/E 变化。所以做不出"阈值下降"。

3. **顶点阈值 0.85 是硬编码的**，没有按情绪强度分布标定。

## 五、合并后的完整方案

两套是正交的，可以叠：

```
心识的贡献                    本模型的贡献
─────────────────────────────────────────────────
19 个生理变量（可裁剪）    +   评估五闸门（R/C/G/K/N）
关系放大 warm/cold         +   状态扭曲评估（L/E 改变阈值）
顶点/未接住 (peak/unmet)   +   三层时间常数（ALMA）
按情绪指定半衰期           +   社会情绪读出（归因+规范）
温度公式（改采样）         +   规则抽取器（可审计）
HPA 负反馈                 +   负荷 L（稳态负荷）
```

**最该先做的三件事：**

1. **关系放大**（最低成本，最高收益）：把 `trust` 从"影响归因"扩展成"影响事件强度"
2. **顶点机制**（补上本模型缺的整块）：按 0.60 标定，只在密集连击时触发
3. **温度公式**（绕过模型表演）：把状态直接接到采样参数

## 六、一个反过来的问题

心识的正则匹配是 `if (/(吓|凶|骂)/.test(t)) cortisol += 0.15`——**词表命中就直接改激素，不经过评估。**

这有个好处：**简单、可预测、不会漂。** 我的五闸门更"正确"，但每个闸门都要从文本里抽，抽错了整条链都错。

**在小场景、固定话术下，正则可能比评估层更可靠。**

所以真正的问题不是"哪个更好"，是：**你的角色对话是开放域还是半固定？**

- 开放域 → 评估层（我这套）
- 半固定（客服、游戏 NPC、特定人设）→ 正则更稳

这一条决定了后面所有取舍。
