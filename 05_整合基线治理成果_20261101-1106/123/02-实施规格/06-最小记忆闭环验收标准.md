# 最小记忆闭环验收标准（第一阶段原型）

> 生成：2026-11-04 ｜ 维护位置：`E:\[PROJECT]\work-交付包\06-最小记忆闭环验收标准.md`
> 目的：定义"Memory Core 最小记忆闭环"实验的输入、步骤、验收项与停止条件。**验收目标不是"能查到"，而是能解释为什么查到、数据来自哪里、修改后是否一致、出错后能否恢复。**

---

## 一、实验输入（人工准备的固定数据集）

准备一份 `tests/fixtures/dialogue.jsonl`，至少包含：
- 6 段中文对话（每段 4–8 条消息），覆盖：自我披露（"我最近在考虑德国读研"）、稳定属性（"我喜欢简洁直接的交流方式"）、承诺约定、未完成话题、专有名词首现、纯寒暄（**应被黑名单过滤**）；
- 1 组英文 + 数字 + 型号混合消息（如 "STM32F103 的 USART2 波特率设 115200"），用于验证 T04；
- 1 条含敏感信息的消息（如 API key 样例），用于验证**黑名单/脱敏**。

## 二、七步闭环步骤

| 步 | 动作 | 验证点 |
|---|---|---|
| 1 | 从对话生成一条候选记忆 | 走 M03 候选逻辑（本阶段可用规则版），输出含 `origin{messageSeq,sender,at,channel,trigger}` |
| 2 | 人工确认后写入 SQLite | 走 M01 事务；写入后 `memory` 表有版本号，Outbox 有事件 |
| 3 | 同时建立全文与向量检索数据 | FTS5 行存在；向量检索层可命中；两者由 Outbox 消费生成（不是绕过 Outbox 直写） |
| 4 | 用自然语言查询记忆 | 三路（关键词/向量/时间）各自返回，RRF 融合后 top-K |
| 5 | 返回相关记忆及其来源、版本 | 结果含版本号与 origin；**不含**内部 ID/检索分数（D19 呈现原则） |
| 6 | 修改或删除记忆后，检查各索引是否同步 | 更新正文→向量重算（B-011 原则）；删除→tombstone→FTS5/向量层同步消失；Outbox 无积压 |
| 7 | 模拟进程中断，再恢复数据库和索引 | kill 进程→重启→一致性校验通过：SQLite、FTS5、向量三者可对账一致（T08） |

## 三、验收清单（全部通过才算 P3 完成）

```text
[ ] A1 写入路径唯一：无任何代码路径绕过 M01 事务直写 SQLite
[ ] A2 候选不入库：未确认的候选记忆存在于候选池（TTL 7 天），不出现在正式检索结果
[ ] A3 黑名单生效：纯寒暄/敏感信息不产生候选或已被脱敏
[ ] A4 来源可追溯：每条正式记忆可回答"哪个模型、哪套参数、哪种文本处理规则生成"（B-010 字段齐备）
[ ] A5 三路检索均可用：关键词（FTS5）、向量（FLAT）、时间过滤各自独立可用
[ ] A6 RRF 融合稳定：同输入同输出；k 为配置参数
[ ] A7 呈现合规：返回自然语言内容+版本+来源，无内部 ID/分数
[ ] A8 预算生效：注入内容不超过 recall.budgetTokens
[ ] A9 修改同步：edit 后向量与 FTS5 与正文一致（含"正文变了必须重算向量"）
[ ] A10 删除同步：remove 后两层均消失；"A 层无对应记录"不算失败（精确匹配语义）
[ ] A11 恢复一致：进程中断后重启，对账脚本报告 SQLite/FTS5/向量 0 差异
[ ] A12 备份可恢复：从 backup 恢复后 A11 通过
[ ] A13 权限挂载点存在：M02 输出前有 permissionCheck() 位置；接口契约默认 DENY（隔离测试环境显式配置测试授权替身，生产禁止 allow-all 回退，见 `15` §5.6）
[ ] A14 无红线违规：代码中无 reinforce 写入路径；未触碰 D:\qq-bridge；正式设计文件未被修改
[ ] A15 偏差清单：与 m01/m02 的所有实现偏差已列入 PROTOTYPE-PROGRESS.md，等待裁决
```

## 四、报告格式（验收时提交）

1. 实验环境（Node 版本/驱动/选型方案 A 或 B）；
2. 七步闭环的实际运行输出（非"应该可以"）；
3. A1–A15 逐项结论（通过/不通过/模拟验证）；
4. 与 m01/m02 的偏差清单 + 建议裁决选项；
5. 遗留问题与下一里程碑建议。

## 五、停止条件

```
A1–A15 全部有结论 → 输出报告 → 更新 PROTOTYPE-PROGRESS.md →
确认红线未触碰 → 停止，等待用户输入「继续 P4」（进入 M03/M04/M05 需单独授权）
```

> 任何一项涉及红线的失败（A14）→ 立即停止并报告，不得继续。
