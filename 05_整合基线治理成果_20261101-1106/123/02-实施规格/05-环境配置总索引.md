## 二、环境搭建步骤（P0 里程碑）

```powershell
# 1) 安装 Node.js LTS（若 node:sqlite 验证通过需 22+；否则 20 LTS + better-sqlite3）
node -v

# 2) 原型目录（独立，禁止放在 D:\qq-bridge 内或其下）
mkdir E:\prototype\memory-core
cd E:\prototype\memory-core
npm init -y

# 3) 依赖（按最终选型安装其中一组，不要全装）
# 方案A（Node 22+）：无需驱动依赖
# 方案B：npm i better-sqlite3
# 向量层（规格 14 定稿用 LanceDB）：npm i @lancedb/lancedb
```

> ⚠️ 若 npm 安装需要网络且当前环境受限，先完成"零依赖"路径：Node 22 的内置 `node:sqlite` + 纯 JS FLAT 向量检索 + mock embedding，同样能跑通 P0–P3 闭环。

## 四、配置项清单（原型必须外置，不得硬编码）

| 配置 | 默认值 | 说明 |
|---|---|---|
| `db.path` | `./data/memory.sqlite` | SQLite 权威库路径 |
| `vector.store` | `lancedb`（规格 14 定稿；实现仍须走 VectorStoreAdapter 接口，禁止业务代码直连） | 向量存储适配器选择 |
| `vector.dim` | 1024（**原型参考值**） | 必须与实际加载模型一致；**不能因配置写了 1024 就强制把其他模型向量改成 1024 维**；换模型必须换空间并走 B-011 迁移路径 |
| `embedding.provider` | `mock` \| `ollama` | mock：确定性伪向量（可复现测试）；ollama：现网参考实现 |
| `embedding.model` | `bge-m3` | 仅作为接口参数，不写死业务逻辑 |
| `fts.tokenizer` | `unicode61` / 可替换中文分词器 | 分词器可替换 |
| `rrf.k` | 60（默认配置，非最终裁决；`14` 规格同值） | RRF 融合参数 |
| `recall.topK` | 5（默认配置，非最终算法裁决；融合层召回 Top-K 为 50、排序保留 Top 20，见 `14` 规格） | 召回条数 |
| `recall.budgetTokens` | 1200（**默认配置，非最终算法裁决**） | 注入预算，**单位是 Token，用 Tokenizer 估算**。⚠️ **Token ≠ 字符**：现网的"≤1200 字"是字符限流，1200 字 ≈ 远多于/少于 1200 Token 取决于语言与分词器，**不得把两者划等号**；另设 `recall.budgetChars`（字符上限）单独生效，二者取更严者 |
| `recall.budgetChars` | 1200（现网字符限流参考） | 字符数上限，与 Token 预算独立计算、取交集 |
| `outbox.pollMs` | 1000 | Outbox 轮询间隔 |
| `backup.dir` | `./backup` | 备份目录 |

## 六、已知坑与纪律（来自项目审查经验）

1. **编码**：所有文件 UTF-8（无 BOM）优先；处理中文文本时**不要用 PowerShell 默认编码读写**，优先 Python/Node 原生 IO；关键文件操作前后记 SHA256。
2. **不要用 SQLite rowid 做业务 ID**（m01 D4 明令）。
3. **不同 embedding 模型的向量，即使维度相同也不得混在同一语义空间排序比较**（B-011）。
4. **同步 Retain 会拖死回复**：凡涉及 embedding 的写入一律异步（`async: true` 不可改 false）。
5. **检索结果必须过权限终检（生产默认拒绝）**：M02 输出前留 `permissionCheck()` 挂载点，接口签名与调用位置现在固定。M05 未实现期间，**接口契约默认返回 DENY**（fail-closed）；仅显式配置的隔离测试环境允许测试授权替身，**不得使用默认 allow-all 作为生产回退**（`15` §5.6）。不得让"数据库过滤"替代访问规则。
6. **D8 备份恢复**：只看"备份成功"不够——恢复后必须能重建一致的检索状态（FTS5/向量可从 SQLite 重建，T08 验收）。
7. **零运行验证 ≠ 已验证**：凡是 mock/模拟测试，输出报告中必须显式标注"模拟验证"。
