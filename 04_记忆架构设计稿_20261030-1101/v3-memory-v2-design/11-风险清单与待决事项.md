## 五、本设计明确拒绝的"看起来能省事"的做法

| 做法 | 为什么不 |
|---|---|
| 把人格也纳入 Ledger | 已验证的失败路线（`04` §2.2） |
| 用 `approved` 修群聊死锁 | 把"没审"伪装成"审过"（`03` §7） |
| 把 `allowed()` 塞进 `canRead` | 运维动作会破坏数据可见性（`03` §6.1） |
| 用 `estimateTokens` 报省了多少 token | 无法审计，且会去凑数（`09` §1） |
| 建通用任务队列 | 没有需要重排/依赖/取消的任务（`02` §4） |
| 新建 MCP server | 会动 `SAFE_PREFIXES`（`05` §7） |
| 让 Reflect 拥有删除权 | 归因于"归纳不覆盖事实"的底线（`07` §1） |
| 只靠 ACL 保护 dump | R6 明确否定（`04` §7） |
