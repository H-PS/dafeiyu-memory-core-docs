## 一、R2 是什么

R2 把 R1 的"决策钉死版"与 19–23 号的事实核查、设计影响、压力审查、边界澄清结果**合并为一份可直接用于实施评审的最终设计基线**。

- **决策口径**：以 19–23 号报告 + 本目录决策寄存器（`01`）为权威；早先报告（Rev3/Rev3.1/FD/R1 与 19–22）是**历史证据**，不是竞争性活跃规范。
- **事实口径**：严格区分 `CONFIRMED`（有 `文件:行号`）/ `INFERRED` / `UNCONFIRMED`，绝不把推断或建议写成已实现事实。
