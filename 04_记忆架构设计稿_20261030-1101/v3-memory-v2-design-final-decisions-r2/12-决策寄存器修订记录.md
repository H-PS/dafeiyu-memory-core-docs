## 二、逐项记录

### 修正 1 · B-2 reset 范围

| 项 | 内容 |
|---|---|
| 原措辞 | "三条 reset 路径统一 `credential.rotate`；旧 token 立即失效" |
| 修订措辞 | 三条会话级 reset 路径用 `credential.rotate`；`workspace/reset` 用 `credential.retireAll`；两者共享凭据原语、不共享事务 phase；workspace/reset 有独立恢复语义 |
| 原因 | 原句把 workspace/reset 与三条会话级 reset 混为一谈，与 23 号 §四"workspace 用 retireAll、无投递语义"矛盾 |
| 关联证据 | 23 号 §四（B/C/A 用 rotate；workspace 用 retireAll + 独立批次事务） |
| 类型 | 澄清 |
| 遗留不确定 | 无（决策意图未变，仅显式区分） |

### 修正 2 · D-8 幂等保留

| 项 | 内容 |
|---|---|
| 原措辞 | "requestId→结果索引随 journal 存续；压缩保留未完成 batch + 最近 N=50 + 全部索引行" |
| 修订措辞 | 七条完整规则（每个 requestId 解析到完整可重放终态 / 索引永不指向已删结果 / 未完成保留至终态 / 已完成 ≥7 天 / 压缩以索引+结果为同一保留单元 / 最近 50 为附加不替代下限 / 重放返回原始结果不轮换）+ 所需元数据 `{requestId,batchId,keys[],status,overallResult,perKeyResults[],completedAt}` |
| 原因 | 原规则未保证"保留的 requestId 永不指向缺失结果"，也缺所需元数据定义（23 号 Issue 3 明确要求） |
| 关联证据 | 23 号 §五（Issue 3 幂等保留不一致） |
| 类型 | 修正 |
| 遗留不确定 | 无（元数据字段已列出；journal 格式实施时据此落地） |

### 修正 3 · C-3 双损恢复

| 项 | 内容 |
|---|---|
| 原措辞 | "认证面=corruptRecovery 确定性自愈；事务面=控制台人工逐 key + DSH 侧人工归档；corruptRecovery 连续失败→fail-closed 403" |
| 修订措辞 | 四目标分列（认证恢复 / reset 事务恢复 / SocialV2 状态恢复 / DSH 会话清理）；认证恢复仅在恢复 key 集被证明含全部凭据（含孤儿）时才称"确定性"，否则保持受控恢复；事务/状态/清理三面不可自动 |
| 原因 | 原句"确定性自愈"未限定覆盖证明前提，违反"不得无条件宣称确定性"（23 号 Issue 2 / 23 号 C-3 修订） |
| 关联证据 | 23 号 §四、§十；07 号 E-15（凭据持久副本=social-v2 字段） |
| 类型 | 修正 |
| 遗留不确定 | 凭据出 S 迁移完成后是否可能产生孤儿凭据文件 → 新增 **V-8b 实施期验证**（见 01 §六·B） |

### 修正 4 · C-7 锁范围

| 项 | 内容 |
|---|---|
| 原措辞 | "同步变更零锁 / 跨 await 变更 fencing / 多 phase 操作 per-key 锁；锁序 token→memory→ledger；锁内禁网络" |
| 修订措辞 | 明确三点：①同步变更不取 per-key 锁（事件循环原子）②异步变更须捕获 epoch + 写前复验 ③多 phase（reset/credential/commit/ledger）用锁；锁序仅在确实需要多把锁时适用；持锁禁 await 网络；无新证据不引入全局快照锁；**不是对每个 SocialV2 写加锁的一刀切** |
| 原因 | 原句可能被误读为"所有 SocialV2 写都要锁"，与 23 号 C-7 三级分层不符 |
| 关联证据 | 23 号 §三（三级分层）、23 号 C-7 修订 |
| 类型 | 澄清 |
| 遗留不确定 | 无 |

### 修正 5 · V-8 门禁理由

| 项 | 内容 |
|---|---|
| 原措辞 | "DSH usage 缓存字段（只读核查）｜实施前（M0 前）" |
| 修订措辞 | 明确四项只读核查（usage 是否含三桶 / ledger 是否正确接收存储 / 缺失是否 N/A / prompt 变更是否影响测量基线）；V-8 仅因"测量有效性依赖"阻塞 M0/M1；若 DSH 根本不含缓存字段，则 cacheHitRate 降级 N/A，**不阻塞 M0/M1**（V-8 只阻塞到事实确认为止） |
| 原因 | 原句未说明"为什么阻塞"，易被误读为任意技术依赖；须明确门禁只到测量有效性所需程度 |
| 关联证据 | 20 号 T5-2（`:709` 缺字段恒 0）、09 号 TOK-01 |
| 类型 | 澄清 |
| 遗留不确定 | DSH usage 是否含缓存字段本身仍未确认（这正是 V-8 要查的） |
