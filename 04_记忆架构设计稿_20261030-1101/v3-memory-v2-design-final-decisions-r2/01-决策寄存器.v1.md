# 01 · R2 决策寄存器（唯一权威）

> 本文件是 R2 的**唯一权威决策清单**。凡此处未列的决策，一律视为历史文档的叙述性内容，不是活跃规范。
> 分级标签：**[Correctness]**（正确性必需）/ **[Defense]**（纵深）/ **[Ops]**（运维便利）/ **[Product]**（需主人批准的产品行为）。

---

## 一、记忆权限与隔离（源自 R1 D1/D3，维持不变）

| 编号 | 决策 | 一句话 | 级别 |
|---|---|---|---|
| **A-1** | 群聊来源敏感记忆不跨会话读取 | `canRead` 强制 `record.key === ctx.key`；群来源 `owner_only` 任何聊天会话（含主人私聊）均不可召回，仅 `canReview`（控制台）可见 | Correctness |
| **A-2** | owner promote 关闭 | 后端拒绝 promote 请求（fail-closed），管理端显示"未开放"，配置不提供放开入口；不依赖 UI 隐藏或默认值 | Correctness |
| **A-3** | 权限函数拆分 | `canRead`（agent/reflect）与 `canReview`（admin）分离；admin 永不进召回 | Correctness |
| **A-4** | 分级唯一路径 + 保护序 | `record.scope.contentClass`；`public(0)<uncertain(1)<sensitive(2)`；自动只许不降级；人工降级需 reason+二次确认+审计 | Correctness |
| **A-5** | 隔离区语义 | 全召回排除、仅管理端可见、approve 释放不改范围、永不进候选池 | Correctness |

## 三、凭据与 reset 事务（源自 19–23 号，R2 新增/修订）

| 编号 | 决策 | 一句话 | 级别 |
|---|---|---|---|
| **C-1** | 内存唯一真相 + 同步重建快照 | 禁止持久化捕获的旧快照；**无需全局快照锁**（同步重建天然互斥） | Correctness |
| **C-2** | `getSocialV2State` 单点 fencing | 内置可选 `expectEpoch` 参数；post-await 写前复验；**不以 ensureSession 的检查宣称全局防护** | Correctness |
| **C-3** | 双损受控恢复 | 认证面=corruptRecovery 确定性自愈；事务面=控制台人工逐 key + DSH 侧人工归档；corruptRecovery 连续失败→二代工具面 fail-closed 403 | Correctness |
| **C-4** | 批次从 journal 重建 | intent + per-key done 差集前滚；禁止重枚举；requestId 幂等扩展 | Correctness |
| **C-5** | 清理绑定捕获的 DSH sessionId | 禁止清理时重解析 key→sid；stop/archive 失败非致命 | Correctness |
| **C-6** | 投递层单点注入 + 显式豁免 | reserved2 QQ 唯一出口注入；v1 直投（`:11527`）与内部学习会话（`:2170/:2233`）为豁免；基础 prompt 裸存 | Correctness |
| **C-7** | 三级锁策略 | 同步变更零锁 / 跨 await 变更 fencing / 多 phase 操作 per-key 锁；锁序 token→memory→ledger；锁内禁网络 | Correctness |
| **C-8** | 消灭 `:4624` 固定空对象直写 | 并入 resetTx effect（全量重建） | Correctness |
| **C-9** | 实施阶段枚举 await 型处理器 | grep 配方（auth 行与 save 行之间含 await）；凭清单，不假设 | Ops |
| **C-10** | 队列/journal/dump 三处无凭据材料 | 基础 prompt 裸存；投递时注入 | Correctness |

## 四、R2 新增约束（源自 23 号 D-1～D-8）
