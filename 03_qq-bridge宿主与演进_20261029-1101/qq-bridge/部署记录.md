## 关键配置（血泪换来的）

### 1. provider 名（最容易错）

```json
"dsh": {
  "provider": "deepseek-account",   ← 必须是 account，不是 official！
  "model": "deepseek-flash",        ← 对的
  "reasoningEffort": "max"
}
```

**错的写法 `deepseek-official` → 报 `session/model-unavailable`（错误信息还被审计层隐藏成"含敏感信息，已隐藏"）**

**正确值来源**：`~/.dsh/storages/session_projcache/sessions/*.json` 里的
`record.rows.modelSelection.val.lastUsed` = `{provider: "deepseek-account", model: "deepseek-flash"}`

### 2. 启动方式（必须用户双击）

```
我（工具里）起的进程：
  → 命令结束就被杀（进程树被清理）
  → 服务全死

用户双击 .vbs：
  → 由 explorer 启动，独立进程树
  → 能长期活着
```

### 3. npx 不能用于隐藏窗口

```
npx.cmd 内部要找 PATH 里的 node
→ 隐藏窗口启动时 PATH 没有 node → 静默失败

必须直接调：
  C:\Users\[USER]\.workbuddy\binaries\node\versions\22.22.2-6\node.exe
  + C:\Users\...\npm-cache\_npx\1e7f6d9597241db0\node_modules\@deepseek-ai\dsh\lib\bin.js
```

### 4. VBScript 的三个坑

```
① 文件里有中文（UTF-8）
   → VBScript 按 ANSI 解析 → 乱码 → 引号错位 → "未结束的字符串常量"
   → 解法：内容全英文（纯 ASCII），中文只留文件名

② ws.Exec("netstat") 会闪黑框
   → 轮询时每调一次闪一次
   → 解法：ws.Run "cmd /c netstat > 临时文件", 0, True 然后读文件

③ 引号嵌套用 "" 容易错
   → 解法：用 Chr(34) 拼接
```

### 5. DSH 启动要等 30-35 秒

```
6 秒能监听 3080 的情况有，但偶尔要 30 秒
→ 脚本里等 35 秒再验证
```

## 桌面四个脚本

```
大肥鱼-启动.vbs   检查端口 → 缺什么起什么 → 各自验证 → 弹总结
大肥鱼-状态.vbs   [OK]/[--] 逐项 + 3/3 判断
大肥鱼-停止.vbs   只杀 node.exe + SnowLuma.exe（不碰 QQ 客户端！）
大肥鱼-重启.vbs   先停 3 秒再起（启动逻辑内联，不调中文名脚本）
```

**⚠️ 停止脚本曾误杀 QQ.exe → 你的 QQ 掉线。已修正，现在不碰 QQ 客户端。**

## qq-bridge 能力清单

```
消息       私聊/群聊、图片、语音、文件、引用回复、戳一戳
人格       roles/ 目录（PERSONA.md / STYLE.md 热读）
记忆       memory 默认开，按轮数压缩，每日摘要写 MEMORY.md
主动搭话   social.proactiveEnabled，条件：你 N 分钟没说话 + 概率
群聊准入   非 @ 消息先进"要不要说话"判断，不进 agent 队列（省 token）
审批桥     agent 提问/工具审批 → 转发 QQ → 你回"通过"/"拒绝"
控制台     127.0.0.1:3100（token 在 state/console-token）
token 看板 按群/好友/轮次统计用量和花费
```
