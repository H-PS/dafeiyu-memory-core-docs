## 二、链路 B · 白名单 → 消息处理

```
config.json
├─ allow.private[] / allow.groups[]        config.json:28-36
├─ deny.private[]  / deny.groups[]         config.json:37-40
└─ allowAllWhenEmpty: false                config.json:41
   │
   ▼
allowed(kind, id, cfg)                     bridge.js:1358
   1. s = String(id)                        ← 兼容 OneBot int64 数字/字符串
   2. denyList = cfg.deny[kind] ?? cfg.deny[kind+'s'] ?? []
      if (denyList.includes(s)) return false          ← deny 优先
   3. allowList = cfg.allow[kind] ?? cfg.allow[kind+'s'] ?? []
      if (allowList.length > 0) return allowList.includes(s)
   4. return cfg.allowAllWhenEmpty          ← 空白名单默认"全拒"
   │
   ├─ 调用点 1：modeAllowed :2672（聊天/仿真模式）
   ├─ 调用点 2：:4226（控制台发消息前，403 "目标不在白名单内"）
   ├─ 调用点 3：:4348（创建会话前兜底）
   ├─ 调用点 4：:6599（转发/群操作前）
   └─ 调用点 5：:11323（/status 显示"白名单 通过/拦截"）
```

**关键语义（已确认）**：

1. **deny 优先于 allow**，所以"在黑名单里"即使也在白名单里也会被拒。
2. `allow` 为空 + `allowAllWhenEmpty=false`（默认）→ **全拒**。这是 fail-closed，不是"默认放行"。
3. 单复数两种写法都兼容（`group` / `groups`），这是历史兼容，**新增配置时应统一用复数**。
4. id 一律 `String()` 后比较，避免 `[GROUP_ID]`（数字）与 `"[GROUP_ID]"`（字符串）不匹配。

**管理员不前置于白名单**（已确认）：`allowed()` 里**没有 ownerQQ 特权分支**。也就是说主人自己的私聊号也必须写进 `allow.private`（当前 `config.json:29-32` 确实写了 [OWNER_QQ] 与 [SECOND_QQ]）。**"管理员豁免"体现在别处**（审批、命令、静默模式），不在白名单层。

### 3.2 三重归属校验


> ⚠️ **这是本盘点最重要的一条事实**：`retireSession` **会重置 agentToken**。
> 任何"会话轮转"方案（包括 Memory V2 的 `rotationTx`）都必须在此之后**重新下发令牌**，否则 agent 的所有工具调用会立刻 403。

### 3.4 `/reset` 与 `retireSession` 的差别

| 动作 | `/reset`（`:11268-11319`） | `retireSession`（`:2763`） |
|---|---|---|
| 清会话映射 | 是 | 是 |
| 清按 key 缓存 | 是（逐个手写，25 处） | 是（`forgetConversationCaches` 8 个 + 12 个 sessionId 级） |
| 重置 agentToken | `forgetAgentToken(key)` | 重置为新随机值 |
| 清 B 层社交记忆 | **是**（`socialV2.conversations.delete(key)`） | 否（只动 token 等字段） |
| 清 recentMessages/unread | 是（`social.recentMessages.delete`、`social.states.delete`） | 否 |
| 停 DSH 侧工作 | `stopSessionWork` + `archiveSession`（`await`） | 同（异步 `void`） |
| **动 A 层向量库** | **否** | **否** |
| 增量 `sessionEpoch++` | 是 | 否 |

**【已确认结论】**：现有 `/reset` 的语义是"清上下文 + 清 B 层，**保留 A 层**"。这直接回答了 Memory V2 的 **D-23**（reset 是否清 A 层）——**现状就是不清**，改成"清"属于行为变更。
