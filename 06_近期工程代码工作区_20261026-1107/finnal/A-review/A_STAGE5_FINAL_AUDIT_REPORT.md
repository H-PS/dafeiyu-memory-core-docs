### 5.2 关键发现：13.2 四条件缺少整体有效性门（**P0 候选，Agent-07 发现，主审验证成立**）

**事实**：
- 13.2（L90）：「L3 版本级确认 = 检查 I **整体** passed ∧ 检查 II passed ∧ **该版本**检查 III 判定 complete ∧ 记录关联一致」——**四条件中无「整体有效性=passed」**；
- 4.3b（**L25**）：「**仅当整体证据有效性=passed 且**特定版本满足 complete 及其他 L3 条件时，**才**产生有效的版本级 L3 确认记录」；
- 13.4a/c（L95/L97）：任一必需检查 failed/not_executable → 整体 failed/not_executable；
- 13.7（L108）：局部 pass 不得覆盖整体。

**复现案例**（假设输入）：
```
版本甲：检查 I 全通过、检查 II 通过、检查 III=complete
版本乙：检查 III=not_executable（引用对象不可取得，13.5c）
→ 13.4a/c：整体有效性 = not_executable
→ 4.3b：不得产生任何确认记录
→ 但 13.2 字面四条件对「版本甲」全部满足 → 版本甲可获 L3
```
**判定**：**13.2 与 4.3b 存在实质冲突，13.2 缺少「整体有效性=passed」这一合取项**。
**影响**：①正面逻辑漏洞——单项/版本级通过可绕过整体门；②使 13.7「局部与整体分离」在 L3 判定处失效；③与 4.3c（L26）「整体有效性 ≠ passed 时不产生确认记录」直接冲突。
**级别**：**P0**（核心模型逻辑不成立——L3 确认条件不完备）。
**⚠️ 双重验证**：Agent-07 独立发现 + 主审独立核对 L90/L25/L95/L97/L108 五处原文确认。**成立**。

### 6.2 覆盖性三缺口〔确认〕

1. **「已开始但中途中断」无态可落**（非 not_started、非 failed、非 13.5c）；

### 6.3 关键承重：检查 III 在 a/b 型下的状态值〔确认（推理唯一）+ 表述缺口〕

- 13.5c（L102）明示「对应检查记为 not_executable」；但 **13.5a/b（L100/L101）未说明检查 III 状态**；
- 唯一自洽解：**检查 III = passed ∧ 版本 result = unknown**（由 L96 第四项「检查已执行（其结论可为 unknown）」+ L106 两轴分离反推）；

- 故 13.5a/b 的可满足性**依赖这一未明示的读法** → 表述缺口（Agent-02 + Agent-03 双代理同现）。

### 6.4 not_executable 无退出条件〔确认〕

- L97（13.4c）为**绝对式**，无「数据后至可重检」例外；
- L73（12.3c）主语是**附录 F 程序级前置**，非个案重检路径；
- 请求级终态清单（L31）**不含任何「无法核验」态**；
- **判定：not_executable 在检查级与整体轴内无退出条件 → 吸收性状态**；结合 6.5 的请求级缺口，该情形**既不能转 passed，也不能落任何登记终态**。

### 7.2 核心命题验证：**成立**，但有一条承重条款〔确认〕

> 命题：a/b 型在满足其他条件时允许整体 passed；c 型不得使整体 passed。

- a → L100「可以 passed」；
- c → L102 + L97 + L96 末句；

- **该括注是 b/c 的唯一分界**：把「语义映射证据可核验性」排除出「必需引用核验」集合 → b 型不触发 13.4c；**若删去或误读 → b 型被第五项吞并 → 整体恒不得 passed**；
- **判定：该括注是承重条款，冗余度为零**（Agent-03 发现，主审逐字复核 L96 确认）。

### 7.3 边界判据与缺口〔确认〕
