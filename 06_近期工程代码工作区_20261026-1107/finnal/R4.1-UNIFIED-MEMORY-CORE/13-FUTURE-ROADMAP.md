## 一、检索与融合类

### F-01 Cross-Encoder 重排
- 解决问题：RRF 名次融合不建模 query-document 细粒度交互。
- 原理：双塔召回后对 top-N 逐对交叉打分重排〔研究证据〕。
- 对 V1 优势：相关性排序质量提升〔一般工程经验〕。
- 适用条件：候选已收窄至数十~数百；延迟预算允许逐对推理。
- 成本：延迟显著上升（逐对前向）〔工程经验估计〕；显存〔无法核实〕。
- 接口影响：M02 排序阶段重排器插槽（C28，L1）+ top-N 参数。
- 迁移路径：RRF 主序→top-N→重排；保留原序降级（F4 跳过）。
- 参考：B-02 §4.4（其对照表数字已被 B-02 按 B-015 拒用）。
- 重评触发：自有测试集就绪且 RRF 基线稳定；或延迟预算放宽。**Roadmap Phase C 的 bge-reranker-v2-m3 仅为示例，非设计决定。**

### F-02 学习型融合
- 解决问题：RRF 等权名次融合忽略渠道质量差异。
- 适用条件：**足量标注查询-结果对 + 评测 harness 稳定 + RRF 进入平台期**（寄存器 D-EXP-06 准入原文；**"≥2000 标注对"的量化出自 B-07/子 Agent E，非寄存器原文——补读核验出处修正**）。
- 迁移路径：与 RRF 并行 A/B 影子；不显著即弃。
- 重评触发：三条件齐备；一次只放开一个参数面。

### F-03 加权分数融合
- 解决问题：RRF 丢弃原始分数信息。
- **⚠ 冲突**：寄存器 D-OK-19 已确认"多路分数只经名次融合不直接相加"——**取向相反，启用须先取新裁决**（B-07 §11.6）。
- 适用条件：四渠道量纲归一化方案验证通过（BM25/余弦/结构化不可比问题）。
