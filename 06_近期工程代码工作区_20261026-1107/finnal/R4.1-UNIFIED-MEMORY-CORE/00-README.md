## 一、系统一句话

为 DSH QQ 聊天机器人构建的**长期记忆能力层**：五模块（M01 存储 / M02 检索 / M03 提取 / M04 整合 / M05 权限）＋ 三个协同扩展（Psychology / Persona / Dream），让聊天 LLM 在长期互动中记住事实与经历、理解用户与关系、按需检索相关记忆、根据新信息修正旧记忆，并以较低 Token 消耗保持互动连续性。

**A/B 是审查分工，不是架构分工**——本目录只有一套统一系统。A 侧（Event-L3 证据链）与 B 侧（算法可替代性）的全部有效结论已回填到对应文档。

## 四、红线（从裁决台账继承，本方案全文有效）

1. **reinforce 禁写**：E14 未落地**且 B04 回传链路未确认前**，只预留 schema，禁止写入（台账 D-AP-05 + 增补层 W-3；红线原文含两条件，不得只引其一）。
2. **M03 候选 / M04 裁决不可合并**（D-AP-01/W-5）。
3. **C40 权限引擎不可插拔**（D-AP-07）；M05 是唯一判权权威，LLM 禁判权。权限记录持久化由 M01 负责（m05 §13.1）——B-058 存储表缺位已列为 V1 阻断项。
4. **心理层不直接取得 M02 排序权**：台账 X-1 delta-only 影子验证；ME-1 语料缺失前不得启动影子退出评估（台账 I-4）。
5. **L3 实现、测试、启用全部暂缓**：F-CK-1~10 全部未核查前 L3 全链不可用；且 E-1 与注入契约存在结构性互斥（N-14，红队 RT-01），先裁互斥再做任何 L3 实现设计。
6. 本方案是**设计整合授权**的产物，不是实现授权。不修改源码、不接入真实 QQ 机器人、不启动生产实现。
