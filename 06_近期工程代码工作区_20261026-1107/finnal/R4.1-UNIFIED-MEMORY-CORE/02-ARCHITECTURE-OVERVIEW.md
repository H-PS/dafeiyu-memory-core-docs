## 一、系统定位与总原则

**记忆库是聊天 LLM 的长期记忆能力层**，不是项目文档知识库，也不是聊天记录存储。它服务三条主线：

1. **记得住**：从对话中提取值得长期保留的信息（事实/偏好/事件/计划/关系）。
2. **想得起**：在当前对话需要时检索出相关记忆，注入 Prompt 参与理解与回应。
3. **不乱说**：不确定的保留不确定性，检索不到的不编造，过期的旧信息不当作当前事实。

四条总原则（继承设计宗旨）：

| 原则 | 落实 |
|---|---|
| 节省上下文与 Token | 按需检索、动态预算、少而准注入（M02 D7/D20）；摘要+cue 索引主体（D-AP-04 已裁方向） |
| 单一权威源 | memory.sqlite 唯一权威（M01 D1）；M02 检索唯一编排权威；M05 判权唯一权威；M04 §6.2 LLM 唯一入口（D-AP-02） |
| 模块边界不可合并 | M03 候选提取 / M04 整合裁决不可合并（D-AP-01/W-5 已裁）；每条跨流接口生产方/消费方唯一 |
| 分阶段演进 | V1 独立闭环（12 号）；Future 独立归档（13 号）；触发器驱动演进（D-AP-08） |

  │    memory.sqlite（唯一权威） + cache.sqlite（可重建缓存，不备份）
  │    + LanceDB（FLAT 向量） + FTS5（中文全文） + Outbox 索引同步

  │       裁决前以 m02 D3 四渠道原文为设计基线——两形态并存说明见 06 §1.2）
  ├─ M03 提取与候选生成（只产候选，不写正式记忆）
  ├─ M04 整合/内部一致性维护与视图维护（裁决入库；Model Gateway 唯一 LLM 入口）
  └─ M05 权限与访问控制（唯一判权；Fail-Closed；不可插拔）
  +
  ├─ Psychology（PsyStateEngine：PAD+E/L 状态机；影子期 delta-only，无排序权）
  ├─ Persona（现网 Bridge 人格分层改造；CR-08B 待单独呈报）
  └─ Dream（记忆漫游与反思；概念收尾，接口有意暂定 U-3）

**关键事实**（继承 A 侧核查）：qq-bridge 当前未接入记忆库与心理层（F6）；全部为设计文本、零实现；F1（sessions.prompt 契约无关联字段）、F3/F4（无 prompt/assembled 事件、无 correlation 字段）、F8（最终组装阶段待核实）——因此 Event-L3 全链与两阶段模型在 DSH 契约扩展前不可用。

## 三、五模块职责与唯一权威（继承 m01–m05，D-AP-01 红线）

| 模块 | 唯一权威职责 | 明确不负责 |
|---|---|---|
| **M01** | 数据持久化、索引（向量/FTS）、事务、备份恢复、缓存库物理管理、目录迁移 | 不判记忆价值、不判权限、不做业务合并判断（D3） |
| **M02** | Recall 全流程编排：触发判断、四渠道检索调度、RRF 融合、规则排序、去重、四预算、关系扩展遍历（唯一预算持有者 D5）、Memory Context 构建 | 不修改正式记忆、不绕过 M05、不直接访问数据库（L38） |
| **M03** | 异步批量提取候选、R/P/E/T/U 五维初评、三档分流（review/observe/reject） | 不写正式记忆、不决定权限/共享/生命周期（冻结红线） |
| **M04** | 候选终审与价值复审、去重合并、冲突与纠正、Observation 构建、关系维护、视图原子发布、统一任务队列、Model Gateway | 不做检索、不判权、不物理删除（提请求，M01 执行） |
| **M05** | 三 scope（private/group/shared）判定、Memory Share 授权、撤销即时阻断、Fail-Closed、审计 | 不接收消息、不提取、不整合、不管人格行为安全 |

**模块协作核心约束**（跨模块一致性修订后统一表述）：

- 业务模块一律经 M01 Storage API 读写，禁止直接 SQL/LanceDB（m01 D3）。
- 新进入对象一律判权；同请求内有限复用、跨请求一律重验（M05 §10.4 八项重判条件）。
- 删除五方分工：M04 判断 → M05 判权 → M01 持久化+物理清理 → Core 任务体系调度（m01 D7/m04 §9.3）。
- 关系扩展：M02 持预算与遍历，M04 只提供一跳邻居查询（listNeighbors，无 depth/budget 入参）。
- 恢复防复活唯一权威流程：M01 D8 八步（恢复权威库→完整性→删除态→权限态→LanceDB→Outbox→派生含 cache 重建→安全后开放 Recall）。

## 七、架构不变量（全系统强制，任何模块不得违反）

1. 权限判定唯一入口 M05；LLM 永不判权（C40 红线）。
2. 权威写入唯一入口 M01 Storage API（含权限记录——B-058 补表后生效）。
3. LLM 调用唯一入口 M04 §6.2 Model Gateway（D-AP-02，PC-1 前置）。
4. 派生数据永远可重建；缓存不承载授权；已删除内容不得经任何路径复活（M01 D8）。
5. 模型输出永远是提议，必须经确定性校验（Schema/clamp/白名单）。
6. 降级只能"变少变慢"，不得"变宽"（F1–F5 失效行为语义；Pluggable 不变量 6）。
7. Memory Context 为纯数据，不含指令层（X-6 接口图；Pluggable 不变量 5）。
8. 影子模式不自动晋升；心理层不直接取得排序权（X-1/I-4）。
