## 五、V1 验收标准（最低集）

1. **生活化查询测试**（m01 D31/m02 D10 八问 + 权限隔离 + 删除后不可检索）全通过。
2. **拔除测试 7 条**：禁用期间聊天不中断、权限测试全绿、行为符合声明降级、恢复无需人工修数据。
3. **故障注入**：向量路断/FTS 断/权限服务断/缓存丢/模型断 → 按声明降级且不越权。
4. **删除防复活**：删除→索引重建→缓存重建→备份恢复后，已删内容不可达。
5. **Token 计量**：五类消耗可查；注入 token 中位数 ≤ 预算。
6. **权限测试**（m05 §17）：身份/Scope/操作/生命周期/性能五组关键路径全绿。
7. **评测 harness**（若批准）：Recall@5/MRR/错误召回率基线建立。
