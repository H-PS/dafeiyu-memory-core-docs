## 一、检索算法链（M02，编排唯一权威）

### 1.1 触发判断（D2，规则化）
触发条件（提及过去经历/人物/偏好/计划；模糊指代；话题延续；需历史信息才可答）；普通闲聊不主动检索。**第一版不加 LLM 判断层**（接口保留升级空间）。

### 1.2 四渠道召回（D3）
### 1.2 检索通道（两形态并存声明——红队 RT-06 修正）
- **设计基线（m02 D3 原文）**：向量（LanceDB FLAT）/ FTS5 / 结构化 / 关系扩展四渠道，各保留原始分数与名次。
- **简化提案（N-1，待裁）**：结构化降为**硬过滤**（布尔约束不该有名次——"按时间排第 50"会拿非零分压过语义第 1）；向量+FTS **两路 RRF**；关系扩展为融合后扩展（m02 D5 本义）。裁决前以基线为准；两形态并存期间，本方案其他文档提及"两路"处均指 N-1 提案形态。

### 1.3 RRF 融合（方向已定，参数未冻结）
- 设计结论：RRF 名次融合作为统一融合机制（m02 L92 一句；m04 D15 同向）；**不直接相加分数**（寄存器 D-OK-19 取向）。
- 参数五分类（B-07 §5.1）：①方向已定=采用 RRF；②有依据参数=k=60（RRF 论文缺省值——**2023 TOIS 分析报告 RRF 对参数敏感，与本整合原引"不敏感"说法相反，子 Agent E 修正**）；③待验证=k 在中文/本系统渠道结构下的实际效果、depth、权重、候选集不同时的处理规则、**等深截断**（子 Agent E：列表深度即权重偏差——深列表系统性占优，融合前须等深截断）；④需裁决=是否固定 k=60（14 号）；⑤实现期=各路权重/深度/候选预算数值。
- **k 缺省处理**：V1 建议 k=60 起步并纳入参数 ID 规范监控（〔建议〕，待验证后调整；原始名次落盘供离线重放）。
- **绝对置信门槛（N-1 组成）**：RRF 相对分撑不起 D21 高/中/低置信分层——融合外加绝对门槛（cosine<τ_v 或 BM25<τ_b 不入上下文，τ 离线标定），防"最好的坏候选"被当高置信。

### 1.4 规则排序（D4，五因素）
相关性 > 时间适配 > 记忆重要性 > 证据可靠性 > 多样性。**字段缺口（B-023）**：importance/reliability 无权威定义与生成方——V1 降为三因子（相关性/时间/claim_type 置信分层）可执行；importance 生成方案待裁决。**首版不用 Cross-Encoder/LLM 重排**（升级空间保留，重排器插槽 F4：失败跳过用原序）。

### 1.5 时间衰减（D23，研究方向——明确"不是最终算法"）
`S_final = S_vector × F(t)` 仅为初步方向。**三处衰减关系（B-013）**：M02 排序衰减（未冻结）≠ PSYCH 分变量衰减（代码存在未集成，台账 I-7/X-6(台账) 暂缓）≠ Roadmap 衰减 v2（未裁决未排期）。**裁决方向**：V1 只允许**一套**排序衰减（若引入 PSYCH 分变量衰减即连乘同一分数流会重复衰减——条件性风险，当前未发生）。约束（已裁）：last_retrieved 不得作衰减 v2 正向权重输入（D-AP-05）。**〔补读核验〕第四口径加入待裁**：Agent2 E12 主张废弃 12/60/900 三半衰期、改 ACT-R d=0.5+三 β——与 PSYCH §6.2 现值冲突，14 §2.3 已列；**反面证据**：Agent3 报告5 §3.7 现网方案明确"不做 importance/access-count 衰减"——供衰减裁决时对照。

### 1.6 去重与预算
去重键=memory_id（多渠道命中保留各渠道排名）；语义相似在上下文构建层去重、不删正式记忆；时间不同代表状态变化的记忆不视为重复。四预算（D7）：候选数/最终条数/Token/扩展深度，动态分配+硬上限，信息足够即停（D20 少而准）。

## 二、提取算法（M03，冻结 + 审查缺口）

### 2.1 五维评分（§6，冻结框架，参数可配置）
R 复用 0.25 / P 持续 0.20 / E 证据 0.25 / T 时效 0.15 / U 独特 0.15；总分 0–5；权重与阈值（review≥3.5/observe≥2.0）配置化带版本（scoring.version）。硬性约束优先于总分（来源不可信拒绝、explicit 不得自证——B-034 缺口、敏感信息独立通道、已失效不复活）。

### 2.2 分流与暂存（§7）
三档：review→M04 / observe 暂存（有限期限+容量上限+合并机制+新证据触发重评+到期清理）/ reject。暂存不自动晋升。

### 2.3 重复表达口径（§8，唯一权威定义）
同批次合并证据；同源短时不显著提升；跨时间场景独立表达可增强；用户纠正优先；证据关联同一候选不生成大量相似记忆；保留来源与时间。**重复提及≠事实真实性**；M02 D25/M04 §4.3 均引用本节口径。

### 2.4 审查确认缺口（B-030~041）
候选生成机制未定义（B-030，V1 阻断：LLM 提示词结构/输出 Schema/批次组织需补设计）；E 维跨批次悖论（B-031）；时间字段断裂（B-035）；J2 情绪标注零承载（B-038）。→ V1 必须项，14 号。

## 三、整合算法（M04，冻结 + 裁决条件）

- **Decision Provider 三型**（Rule/LLM/Hybrid，可插拔，输出七字段：relation_type/target/confidence/evidence_refs/explanation/suggested_action/policy_version）；Provider 只提议不写库。
- **更新判断五问**：新记忆？重复？补充？时间演变？冲突？（duplicate/complement/temporal_evolution/contradiction/topic_related 五关系类型）。
- **Observation 形成规则**：单次清晰表达→候选不自动稳定认识；多次**独立表达**（口径引用 M03 §8）提高置信度；冲突未决→uncertain/pending；必须可追溯 Fact/Event/Evidence。
- **confidence 计算规则缺失（B-049，V1 阻断）**：Decision Provider 输出 confidence 无计算/聚合/衰减规则——需最小规则设计。
- **〔补读核验〕合并时 affect_* 聚合规则缺失（Agent2 Q16/Q17）**：M04 合并多来源记忆时 affect_* 情绪元数据无聚合规则（M04 为冻结稿零承载）——Agent2 候选方案：intensity 加权平均 / peak-end（0.4/0.25/0.35，待验证）→ 14 §2.4 已列待裁。
- **Model Gateway 分级路由**（§6.3）：普通语义→轻量模型；复杂冲突/Observation 综合→较强模型；高风险低置信→允许升级，仍不确定→待审核。降级（§6.4）：规则能做的继续；语义依赖任务进待处理队列；不用低质量结果覆盖旧 Observation。
- **W-1 前置（未完成）**：m04 §6.2 须补齐 m03 §12 五条故障不变量（失败≠成功/重试幂等/输出必过 Schema/不阻塞聊天/不中断既有读取），补齐前 m03 冻结稿不修订。**〔补读核验拆分〕另存在 D-CH-07 五条 C41 Gateway 约束**（fallback 早于重试耗尽/空 200 不算成功/调用版本落盘/健康按实例/allowed_fails 显式）——与 W-1 五条是两组不同约束，随 Gateway 实现一并落地（02 §五修订 15）。

## 五、Embedding 与索引（M01，方向已定）

- 单一默认模型起步；模型可替换、向量不混用、记录 model/version（D16）；换模型=新索引空间构建→验证→切换→保留旧索引回退。
- **B-010/B-011 缺口**：D19 无显式维度/归一化/分块版本字段；新旧索引并存期查询路由/双写/切换原子性/迁移完成判据未定义（14 号，V1 条件）。

## 六、缓存算法（M02 判定 + M01 执行）

只缓存中间检索候选（向量候选 ID/分数、FTS 候选/排名、关系候选）；不缓存最终授权结果或最终 Memory Context。命中后仍须最新状态校验+M05 判权。失效触发链（B-071 缺口）：记忆/索引/权限变化时由 M02 判定失效、M01 执行——完整触发矩阵 V1 补设计。
