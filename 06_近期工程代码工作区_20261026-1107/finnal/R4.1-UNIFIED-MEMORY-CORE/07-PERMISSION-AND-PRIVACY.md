## 一、权限模型总则（已冻结）

- **M05 是记忆数据访问的唯一权限判定权威**；LLM 永不判权；行为安全由人格/System Prompt 负责，数据访问权限由 M05 强制执行。
- 信任边界：Bridge 是 QQ 身份唯一可信入口（user_id/chat_type/chat_id/group_id/成员资格/request_id）；普通业务参数不得覆盖可信身份字段；身份缺失/无法验证 → 默认拒绝。
- 五身份字段区分：actor_id（操作者）/ author_id（贡献者）/ subject_id（记忆对象）/ owner_id（所有者）/ group_id——不得互代。

## 二、三 Scope 模型（D25，已冻结）

| Scope | 语义 | 关键规则 |
|---|---|---|
| **private** | 绑定 owner_id 的私人记忆 | 默认仅所有者可读；不因群聊提及自动共享；Bot 所有者有全局管理权（本地可信配置 owner_id 认定，变更留审计） |
| **group** | 归属 group_id 的群组记忆 | 当前成员可读；不自动归入发言者私人记忆；保留 author_id 供追溯/纠错/删除申请；群间隔离；**成员退群即失去读取权**；群解散整体停访问 |
| **shared** | 私人记忆对指定群的引用授权 | 引用不复制；所有权不变；每目标群独立授权记录；单群撤销不影响他群；派生记忆不得扩大授权 |

## 三、操作权限矩阵（D6）

| 操作 | 默认权限 |
|---|---|
| Recall/读取 | 当前范围授权成员 |
| Retain/新增 | 可向当前个人/群范围贡献候选 |
| Update/修改 | 所有者或授权管理者 |
| Correct/纠正 | 可提交，Core 校验（提交≠覆盖） |
| Delete/删除 | 所有者或授权管理者（提交≠执行） |
| Share/分享 | 私人记忆所有者主动授权 |
| Revoke/撤销 | 授权所有者或有权管理者 |

高影响操作（批量删除/清库/重置全部共享）本地二次确认；QQ 群普通消息不得触发高影响操作；群管理员身份不自动获得记忆权限。

## 四、统一判定接口（§10，已冻结）

请求结构：request_id/actor_id/action/resource_id/scope/trusted_context → 返回 decision(allow/deny)/reason_code/policy_version/permission_version。判定绑定单次具体操作，不跨请求/对象/操作复用。

**§10.4 单请求内复用**（八项重判条件）：见 03-DATA-FLOW §四。缓存命中≠授权（数据缓存≠授权缓存）。

## 五、Fail-Closed 与用户反馈（§十二，已冻结）

身份缺失/权限服务异常/权限数据不一致 → 拒绝受保护操作；普通聊天继续。拒绝提示不暴露：内部权限规则、其他用户私人内容、无权记忆的存在性。高影响操作被拒时明确告知未执行。

## 六、撤销即时性（§七，已冻结）

撤销成功 → 立即阻断新读取 → 缓存立即失效 → 旧快照不能绕过 → 派生数据按依赖重估 → 状态持久化重启有效 → 清理失败允许重试但不恢复访问。并发：权限版本递增；在途操作提交前复核版本；撤销优先于旧授权。

## 七、W-2 两条绕过路径补强（D-AP-07 附条件，已裁方向）

1. **可信上下文签名**：判权可信上下文由 Bridge/入口层在 request_id 创建时一次性签名固定，下游组件只读不可改，M05 校验签名；manifest 增 `trusted_context_source: entry-only`。**B-068 未落地前不得声称绕过路径已消除**。
2. **影子 diff 日志分级**：影子组件输入先经 M05 判权过滤；diff 日志默认只记 metadata（ID/分数/名次），记正文需显式声明并纳入审计；diff 日志读取本身需判权；manifest 增 `diff_log_classification`。

## 九、隐私与数据保护（D-AP-09 已裁 + D13 已冻结）

- **拒绝第三方托管记忆平台**（永久，推翻须重新裁决）；**不得直接声称"记忆文本不出本机"**——须区分本地持久化与云端模型推理请求，后者另行评估约束。
- V1 简单保护：OS 文件权限 + 备份同级保护 + 不存凭据 + 日志避免完整私人内容；加密/密钥管理暂缓。
- 导出（D26）：保留 ID/类型/正文/时间/来源/版本/生命周期/权限范围；不导出令牌密钥；导入不自动赋权不绕过 M05；**Recall Cache 不导出**。
- K-2 已裁方向：用户可获取关系性内容与互动状态；内部计算参数/系数不默认导出；须逐项确定导出边界（openLoop.text/关系基调/历史峰值/信任度/互动统计）；删除、删号连带、tombstone、缓存和备份语义一并考虑。
- 审计（§14）：最小化审计（11 字段），追加式不可改；不记录完整正文/密码/Token。
