## 一、Psychology（心理状态层）

### 1.1 定位与红线

心理层是**可整体拔除的增强能力**（I-2），不是核心记忆链路的必要条件。**〔补读核验披露〕拔除性张力（Agent2 D-24）**：Agent2 判定"可拆除"实为 L1 级——I-3（schema 预留）/I-12（affect_* 字段）/I-13（运行时态 KV）分别需 m01/m03 变更，与 D-22（Agent2 主张不改任何 R3 冻结文档）存在张力；拔除测试须验证"删状态层后 Core 全绿"，但**字段级残留**（affect_* 列等）不等于功能残留。**G2 硬护栏（I-5 已裁）**：不产生记忆候选、不写人格、不直连记忆库、不触发记忆写入——值得记住的内容必须走 M03/M04 正式通道。

## 三、Dream（记忆漫游与反思）

### 3.1 定位

后台低优先级任务：定期回顾记忆、跨时间跨主题寻找联系、有价值的发现反馈核心用户。**核心原则：可以提出想法，不能把想法冒充事实。** 与 M04 integrity_reflection（内部一致性维护）是**不同功能**，不共用任务标识。

### 3.2 机制

- 探索：随机漫游 + 定向反思混合；定时触发为主、事件触发为辅；限频+任务合并；不强制产出（无发现可无报告）。
- 输出双通道：主动 QQ 私聊反馈（自然简洁）+ Dream Report 独立持久化（M01 D2；与正式记忆分开存放，不参与普通 Recall 事实召回，独立生命周期）。
- 权限：只读当前授权记忆（M05 判权）；报告引用保留权限约束，撤销后重检；不得自动分享/转换/绕过删除。

### 3.3 关系候选边界（与 M04）

Dream 可提交关系候选 → M04 为预期接收方；**接口未冻结（U-3，有意暂定）**；候选 claim_type 必须 inferred/uncertain；**不得直接生成 support 关系**、不直接写 Relation；候选保留来源引用。V1 是否开放该入口按 M04 阶段规划，不因本节增加实施任务。

### 3.4 资源与故障

后台低优先级：不与聊天争资源；资源不足可延迟/跳过；可暂停可恢复；单次失败不影响聊天。
