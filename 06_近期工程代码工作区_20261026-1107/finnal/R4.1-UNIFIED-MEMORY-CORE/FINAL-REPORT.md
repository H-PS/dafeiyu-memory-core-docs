## 一、17 问回答

**1. 现在的完整记忆库究竟是什么架构？**
一套本地单实例 Memory Core：五模块（M01 SQLite 权威存储＋索引；M02 检索唯一编排权威；M03 候选提取；M04 整合裁决＋LLM Gateway 唯一入口；M05 权限唯一权威）＋三协同扩展（Psychology 影子期状态提示层 / Persona 现网人格管线 / Dream 概念收尾），宿主为 DSH＋qq-bridge。A/B 审查成果已回填为 47 项核心修订（audit/INTEGRATION-MATRIX.md），但**架构骨架维持 R3 五模块原样**——A/B 是审查分工，不是架构分工。

**2. 五个核心模块分别负责什么？**
M01：持久化/索引（向量+FTS+结构化）/事务/备份恢复/缓存物理管理/防复活八步；M02：触发判断→四渠道检索→RRF 融合→规则排序→去重→预算→检索后权威校验→Memory Context 构建（纯数据）；M03：异步批量提取候选+五维初评+三档分流（只产候选不写正式记忆）；M04：候选终审/去重合并/冲突纠正/Observation/关系维护/视图发布/统一任务队列；M05：private/group/shared 判定+Share 授权+Fail-Closed+单请求内复用+审计。

**3. 它如何服务聊天 LLM？**
通过唯一注入通道：M02 产出结构化 Memory Context（不含 memory_id/时间戳/分数/内部过程）→ Bridge 注入 DSH → LLM 把记忆当背景素材自然使用（区分事实/推断/不确定/已纠正）；上下文不足时可受控主动 memory_search（Bridge 转交、每次新请求边界、重新判权）。心理层仅提供 ≤50 字有界状态提示（X-7 修订方向），不进人格段、不决定内容。

**4. 记忆如何从对话产生？**
异步 Retain：批次（同会话/同主体/兼容权限）→ M03 提取（V1 方向：规则闸门 L0 丢弃/L1 规则候选/L2 灰区经 Gateway 的 LLM，五维由规则补全）→ 硬性约束校验 → 分流 review/observe/reject → M04 终审（与旧记忆比较五种关系）→ M05 判权 → M01 事务写入+Outbox。当前对话内容不因进入上下文自动成为正式记忆。

**5. 记忆如何存储和更新？**
memory.sqlite 唯一权威（**m01 D4 十表全列：memories/evidence/observations/relations/cue_anchors/dream_reports/tasks/task_checkpoints/outbox/change_log + permissions/share_authorization（B-058 补）= 12 表**）；cache.sqlite 可重建缓存（不备份；N-6 待裁降为进程内 LRU）；更新走版本链：用户纠正优先→旧版标 superseded→新版本→依赖 Observation 重算→旧任务不得覆盖新版本。时间四字段区分记录时间与现实有效时间。

**6. 聊天 LLM 如何检索并使用记忆？**
自动预检索（规则触发）+ 主动检索（DSH 判断）双路径共用 M02 服务；向量+FTS 两路 RRF（k=60 起步，等深截断，绝对门槛建议）+结构化硬过滤+关系 L0/L1 扩展；少而准注入（准确性>相关性>完整性>数量），一条够不注入多条。

**7. 如何避免错误、过期和无权限记忆进入 Prompt？**
四层防线：检索前过滤（仅性能优化不构成授权）→ 检索后权威校验（最新生命周期状态）→ M05 逐条判权（Fail-Closed，同请求内有限复用跨请求一律重验）→ 注入前预算与置信分层（低置信不进上下文，事实/推断/纠正标注保留）。过期/被替代记忆默认不进当前上下文（历史查询例外）；已删除立即屏蔽且不可经索引/缓存/备份/历史版本复活。Event-L3 证据链（候选）进一步验证"记忆确实进入最终 Prompt"，但 F-CK 未核查前 L3 不可用。

**8. 如何控制 Token 消耗？**
四预算动态+硬上限（候选数/最终条数/Token/扩展深度）；按需触发（闲聊不检索）；少而准原则；优化-1 已裁的五类 Token 计量（系统提示词/聊天历史/检索注入/实际注入/模块调用）；Retain 日预算提案（N-8，待裁）；提取层规则闸门省约 80% LLM Token（假设待验收）。

**9. 如何保证长期互动连续性？**
三层记忆（Evidence→Fact/Event→Observation 综合认识）+ 关系维护 + 用户偏好/习惯/人物关系的积累与纠正更新 + Observation 置信度随独立表达增强 + 心理层状态提示（有界）+ Dream 跨主题联想（Future）。同话题连续对话复用已注入内容避免重复检索；记忆更新后旧注入失效。

**10. V1 能实现哪些完整能力？**
见 12-V1-SCOPE §1.1 十项核心闭环（存储/判权/检索/提取/整合/索引同步/删除防复活/受控主动检索/拔除测试 7 条/日志计量）。Event-L3 为"设计闭合+实现暂缓"双层：设计层 12 项修订已写入，实现层待 F-CK 核查与 DSH 契约扩展。
