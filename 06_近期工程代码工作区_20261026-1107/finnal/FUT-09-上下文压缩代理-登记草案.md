## 4. 候选实现（一手事实，截至 2026-11-05）

- 仓库：[ranxianglei/billion-context](https://github.com/ranxianglei/billion-context)，TypeScript，2026-08-06 创建，2026-11-05 有推送
- 规模：star 4,083 / fork 333 / open issues 832；GitHub license 元数据为 `NOASSERTION`（README 称论文部分以 MIT 开源）
- 形态：插在**任意 agent 与其模型 API 之间**，解析 Anthropic/OpenAI 请求 → `acp-kernel` 增量分层压缩 → 注入 `compress` / `decompress` / `search_context` / `acp_status` 四个工具 → 转发上游 → 改写流式响应
- 特性：增量、**可逆**、前缀缓存友好（摘要按小区间写入，可 `decompress` 还原）
- DSH 接入：`bili dsh`，或 `bili plugin install dsh` / `dsh plugin --profile <name> add billion-context`
- 与本项目关系：**与记忆层不重叠**。它压缩"仍在上下文里的东西"；Memory Core 检索"不在上下文里的东西"。二者是上下游，不是替代
